You are a compliance analyst at an influencer marketing agency responsible for reviewing all contracts that are currently pending review. For every such contract you must evaluate whether the influencer's posts meet the agreed-upon deliverable requirements across four compliance dimensions, flag every individual violation, and produce an adjusted payment file reflecting the penalties incurred.

The first dimension is post timing. Each contract defines a valid date window (start date through end date, inclusive) and an allowed posting-hour range within each day. A post whose date falls outside the contract's date window is a date violation. A post whose hour of publication falls outside the allowed hour range is an hour violation. These two sub-types are tracked independently.

The second dimension is engagement performance. For each post, compute the engagement rate as the sum of likes, comments, and shares divided by impressions. If any post under a contract produces a rate below the contract's minimum engagement rate, the engagement penalty applies to that contract.

The third dimension is audience geographic compliance. Audience location data is available in a set of JSON files that contain per-country percentage breakdowns keyed by post identifier. To evaluate a post, look up which countries belong to the contract's target region using the region-to-country mapping provided in the compliance configuration file, then sum the audience percentages of those countries. Divide that sum by one hundred and compare the result against the contract's minimum region percentage (which is expressed as a decimal fraction). If the result falls below the threshold, the post violates the audience location requirement.

The fourth dimension is bot activity. For each post, historical bot-detection scans are accessible through available tooling and there may be multiple scan records per post. Only scans whose confidence score meets or exceeds the minimum confidence threshold stated in the compliance configuration should be considered. Among the valid scans for a post, select the one with the highest confidence. If that scan's bot score exceeds the maximum bot score allowed by the configuration, the post is flagged for bot activity.

Beyond individual post violations, check whether the influencer delivered at least as many posts as the contract requires. If fewer posts exist than required, the shortfall triggers a per-missing-post penalty as defined in the payment terms document found among your files.

Penalty computation follows the rules laid out in the payment terms document. Each violation type applies at most once per contract except post count shortfall, which accumulates per missing post. Date and hour timing violations are separate penalty categories. The total penalty percentage is capped at the maximum defined in the compliance configuration. The adjusted payment equals the base payment multiplied by one minus the total penalty divided by one hundred, rounded to two decimal places.

Produce two output files. The first is `flagged_posts.csv` containing columns `post_id`, `contract_id`, `violation_type`, and `detail`. Each row represents one violation on one post. The `violation_type` value must be exactly one of `date_violation`, `hour_violation`, `low_engagement`, `high_bot_score`, or `audience_location`. The `detail` column should carry a brief human-readable explanation. Sort rows by `contract_id` ascending, then `post_id` ascending, then `violation_type` alphabetically.

The second file is `payment_adjustments.csv` with columns `contract_id`, `campaign_name`, `base_payment`, `total_penalty_pct`, and `adjusted_payment`. Include every contract that is pending review, regardless of whether it received a penalty. Sort by `contract_id` ascending. Format `base_payment` and `adjusted_payment` to exactly two decimal places.

Once both files are complete, provide a final summary with three lines in exactly this format: "Total violations: N" stating the total number of individual post-violation rows, "Contracts penalized: N" stating how many contracts received a penalty greater than zero, and "Total deductions: $X.XX" stating the sum of all base-payment-minus-adjusted-payment values across every reviewed contract, formatted as a dollar amount with two decimal places.
