You are conducting an emergency services resource utilization audit for a metropolitan fire and rescue department. The department operates multiple unit types including engine companies, ladder companies, rescue squads, EMS units, and hazmat teams spread across numerous stations. Your objective is to identify every unit that requires retraining, re-equipping, or both, and to produce a prioritized list ranked by the severity of their deficiencies.

Begin by locating and reading the audit policy configuration file, which specifies the audit reference date, all threshold values used to flag deficiencies, which deficiency types contribute to retraining versus re-equipping scores, the exact keywords that constitute protocol violations in radio transcripts, and the rule for attributing a violation to a specific unit. Separately, read the certification requirements file to learn what certification level is mandated for each role within each unit type. Then read the scoring matrix file, which defines how many penalty points each type of deficiency carries and whether it falls under the retraining or the re-equipping category.

Once you have internalized those parameters, retrieve the complete roster of units through the available listing tool, paging through all results. For every unit, gather its personnel records, equipment inventory, dispatch history across all available pages, and the maintenance history for each piece of equipment. You will also need the outcome report for every distinct incident a unit was dispatched to. All of this information is available exclusively through the provided tools and cannot be obtained from files alone.

At the same time, read every dispatch transcript file found alongside the configuration files. These transcripts document radio communications during incidents and may contain protocol violation keywords. A violation is attributed to a unit when that unit's identifier appears on the same line as one of the violation keywords listed in the audit policy. Count the total number of violations per unit across all transcripts.

For each unit, determine whether it is deficient in any of the following areas. First, compute the average response time in minutes across all of its dispatches by taking the difference between arrival time and dispatch time; if this average exceeds the threshold specified in the audit policy, the unit incurs the slow-response penalty once. Second, examine each person assigned to the unit: if their certification expiry date falls on or before the audit date plus the warning-day window defined in the policy, or if their certification level is strictly below the level required by the certification requirements file for their role within that unit type, count that person as a certification deficiency and add the corresponding penalty. Certification levels rank from lowest to highest as basic, intermediate, advanced, specialist. Third, for each distinct incident the unit responded to, retrieve the outcome report; if the outcome rating is below the minimum specified in the policy, add the poor-outcome penalty. Fourth, multiply the unit's total protocol violation count by the per-violation penalty. Fifth, for each piece of equipment assigned to the unit, find its most recent maintenance record by maintenance date; if the next-due date on that record falls before the audit date, add the overdue-maintenance penalty. Sixth, for any equipment whose condition rating is below the minimum specified in the policy, add the poor-equipment-condition penalty.

After computing all individual penalties, sum them into two category scores for each unit. The retraining score is the total of all penalties whose deficiency type is classified as a retraining factor in the audit policy. The re-equipping score is the total of all penalties classified as a re-equipping factor. The total priority score is the sum of both. Include a unit in the final report only if its total priority score is greater than zero. For the required action label, assign RETRAIN if only the retraining score is positive, RE-EQUIP if only the re-equipping score is positive, or RETRAIN_AND_RE-EQUIP if both are positive.

Save the final output as `priority_report.csv` containing the columns unit_id, unit_name, unit_type, retraining_score, reequip_score, total_priority_score, and action_required, in exactly that order. All score values must be integers. Sort the rows by total_priority_score in descending order; where two units share the same total, break the tie by unit_id in ascending lexicographic order.

In your final response, state the total number of units flagged for action and list the top five highest-priority units by their identifiers and names along with their total priority scores, retraining scores, re-equipping scores, and required actions.
