You are a labor compliance analyst at a manufacturing facility that operates around the clock with employees spread across several departments and union affiliations. Your responsibility is to produce a comprehensive weekly violation report for the week of March 10 through March 16, 2025, identifying every instance where labor law rules, union contract provisions, or internal safety policies may have been breached.

The facility's workforce is organized into departments, and each employee belongs to one of several union locals. Each union local specifies its own break requirements in a contract file you can find among the available documents: the contract defines a mandatory meal break of a certain minimum duration that must be taken once a shift exceeds a specified number of hours, and it also defines periodic rest breaks of a specified duration at regular intervals throughout the shift. A shift that meets the meal break threshold but has no recorded meal break at all constitutes a "break_meal_missing" violation, whereas a shift where a meal break was taken but fell short of the required duration is a "break_meal_short" violation. When an employee's actual number of rest breaks during a shift is fewer than the expected count (computed by dividing the shift length by the required rest interval and subtracting one, rounding down), the shortfall is flagged as "break_rest_missing." To determine these, you will need to retrieve each employee's clock-in and clock-out times from the time punch records, look up what break records exist for each punch, and compare against the union-specific rules for that employee's union code.

Separately, the facility enforces overtime limits. A configuration file among the documents specifies a maximum number of hours per day and a maximum weekly total. Any individual shift that exceeds the daily limit triggers an "overtime_daily" violation. If an employee's total hours across all shifts in the week surpass the weekly cap, that produces an "overtime_weekly" violation. Additionally, any shift on a Saturday or Sunday that exceeds a weekend-specific hour threshold (also found in the overtime configuration) is flagged as a "weekend_long_shift" violation.

On top of this, each department mandates certain skill certifications for its employees. A requirements document lists which skills are mandatory for each department. You must check each employee who worked during the week: if that employee's department requires a skill for which they have no certification record whatsoever, or if their certification expired before the start of the analysis week, this is a "training_expired" violation. Training records can be retrieved on a per-employee basis through the available query tools.

Finally, machine energy usage logs are stored in CSV files among the available documents. Each entry records which machine was operated by which employee, the date, the operating duration in hours, and the total energy consumed in kilowatt-hours. A separate thresholds document provides the maximum allowable kWh per hour for each machine type (identified by the prefix of the machine ID, before the hyphen). When the actual energy consumed exceeds the product of the maximum per-hour rate and the operating duration, this is an "energy_exceeded" violation.

Once all violations have been identified, each must be assigned a severity level. A severity configuration document maps each violation type to a severity level (critical, major, or minor). Sort all violations first by severity in descending order (critical before major before minor), then by employee ID, then by violation date.

Save the complete results as `weekly_violation_report.csv` containing exactly these columns in this order: `employee_id`, `employee_name`, `violation_type`, `violation_date`, `severity`, `details`. For violations that span the whole week rather than a single day, use the date format "2025-03-10/2025-03-16" in the violation_date field. The details column should contain a human-readable description of the specific violation.

Once the report has been written, provide a final summary stating the total number of violations found, followed by a breakdown showing the count for each violation type, and then list the top five employees with the most violations along with their names and counts.
