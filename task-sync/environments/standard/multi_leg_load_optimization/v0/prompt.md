Pacific Shipping Lines has flagged the loading plan for an upcoming multi-leg voyage aboard MV Pacific Horizon for urgent revision. The vessel departs from the loading port with all cargo on board and then makes several intermediate stops to discharge containers before reaching the final destination. Preliminary analysis indicates the current arrangement will cause an unacceptable number of re-handling events at the intermediate discharge ports, where containers bound for later stops would need to be shuffled aside to reach containers that must come off sooner. Several violations of operational and safety stowage rules have also been identified in the existing plan.

Your working directory contains the voyage itinerary documenting the port call sequence and scheduled dates, the vessel's structural specifications including bay layout, dimensions, and weight limits, a plain-text document describing all stowage rules that govern weight ordering within vertical stacks and cell capacity limits, a hazardous materials policy outlining class-based bay separation requirements, and a series of numbered cargo manifests that record additional attributes for each shipment. Among those attributes is whether temperature-controlled stowage is required for the goods inside a given container, even when the physical container is not itself a reefer unit. These manifests are essential because the container registry accessible through the available query tools tracks only whether a container is physically a reefer, not whether its contents independently need temperature control. You must consult both sources to identify every container that requires a reefer-capable cell.

Through the available query tools you can retrieve specifications for every container including its weight, type, destination port, reefer designation, and hazardous material classification. You can also inspect the stowage cells available in each bay of the vessel, review the current loading assignments that constitute the plan under revision, and look up land transport booking schedules at each discharge port showing pickup times and deadlines.

A valid revised plan must place every container in a cell of matching size category, ensure that any container needing temperature control occupies a cell within a reefer-capable bay, keep containers of different hazardous material classes in separate bays while allowing non-hazmat containers to coexist freely with any single hazmat class, arrange each vertical stack so that container weights do not increase from lower to higher tiers, respect each cell's individual weight capacity, and keep the aggregate weight within each bay under the published bay weight limit found in the vessel specifications. Wherever these hard constraints allow flexibility, containers should be positioned so that those discharging at earlier ports rest above those continuing to later ports within the same stack, minimizing re-handling. A re-handling event is counted each time a container above a target container in the same bay and row is destined for a later port than the target and must therefore be temporarily removed during discharge.

Save your revised assignments as `revised_plan.csv` containing columns `container_id`, `cell_id`, `bay`, `tier`, and `row`, one row per container. In your final answer, state the plan's capacity utilization as a percentage to exactly two decimal places, calculated as the number of containers successfully assigned divided by the total container count multiplied by one hundred. Also state the total count of re-handling events your revised plan would incur across all discharge port operations.
