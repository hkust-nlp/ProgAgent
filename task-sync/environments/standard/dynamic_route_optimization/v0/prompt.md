You are a route planning analyst for a municipal waste collection service that operates a fleet of trucks across several residential districts. Every service area in the network contains waste bins fitted with weight sensors that record expected collection weights on each weekday, and each resident subscribes to one of several service tiers that may influence how often their area is serviced.

Your objective is to generate an optimized weekly collection schedule spanning five weekdays, numbered one through five, that minimizes total fuel expenditure and drive time while satisfying all coverage and capacity requirements.

Begin by examining the configuration and policy documents available in your environment. A policy document describes the rules for classifying areas as high-demand or standard, the procedure for assigning trucks to daily area sets, and the algorithm for sequencing stops within each route. A separate tier configuration file defines the subscription tiers and which ones force an area into the high-demand category. A district schedule file maps each district to its primary and secondary collection days. A fuel price file lists current per-litre prices by fuel type. A maintenance file identifies trucks that are unavailable on particular weekdays. Traffic data files, organized by day and segment group under a traffic directory, provide road distances and travel times between every pair of service areas and the central depot; you must read all segment files for a given day to assemble the complete set of travel data for that day.

Query the data sources to retrieve every service area along with its district and geographic coordinates, the expected total bin weight per area for each weekday, the residents in each area together with their subscription tiers, all trucks with their capacity and fuel specifications, and each truck's historical fuel consumption records. From the fuel logs, compute each truck's actual fuel efficiency as total distance divided by total fuel consumed. Cross-reference all of this information with the policy rules and configuration parameters to classify every area, determine its collection days, assign trucks to each day's area set following the prescribed greedy capacity-and-efficiency procedure, and sequence stops within each route using the nearest-neighbour method described in the policy.

Save the resulting schedule as route_schedule.csv with columns in this exact order: day_of_week, truck_id, stop_order, area_id, area_name, expected_weight_kg. Each row represents a single stop on a particular truck's route for a given day. The day_of_week column uses integers one through five. The stop_order column is an integer starting at one for each truck on each day. Values in expected_weight_kg are rounded to one decimal place.

Separately, produce cost_report.json as a JSON object with three keys: total_fuel_cost rounded to two decimal places, total_drive_time_minutes rounded to two decimal places, and daily_breakdown containing an array of five objects, one per weekday, each with keys day, num_routes, fuel_cost, and drive_time_minutes, all numeric values rounded to two decimal places.

In your final response, state the total weekly fuel cost as a dollar amount to two decimal places and the total weekly drive time in minutes to two decimal places.
