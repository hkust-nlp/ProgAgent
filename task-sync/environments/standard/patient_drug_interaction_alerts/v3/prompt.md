You serve as the clinical decision support analyst at a regional hospital, and each morning you are responsible for producing the daily patient safety alert report. The pharmacy department relies on this report to identify every patient who may be at risk due to adverse drug interactions, contraindicated medications given their active medical conditions, concerning laboratory values in the context of their current prescriptions, or cases where a patient has been dispensed a medication to which they have a documented allergy.

The hospital's electronic systems give you access to a comprehensive patient registry along with each patient's current dispensing records, a database of known drug-drug interactions that includes severity ratings and clinical descriptions, the electronic health record of active diagnoses coded by ICD, and recent laboratory test results. Separately, the working directory contains clinical reference documents and operational records that you must consult: documented rules pairing specific drugs with medical conditions for which they are contraindicated, a configuration of laboratory alert thresholds that specify when a particular test result combined with a particular medication warrants clinical attention, the response protocol that defines severity levels together with the exact recommended-action wording for each level and the rules governing which severity levels apply under each patient monitoring classification, ward rosters that list every patient's current ward assignment and their assigned monitoring level, and allergy records maintained by the nursing department that document each patient's known drug allergies.

Four categories of safety concern must be identified. A drug-drug interaction alert is generated whenever a patient is concurrently prescribed two medications that appear together in the interaction database; the severity comes directly from the database record for that pair. A contraindication alert arises when a patient carries an active diagnosis whose ICD code matches a rule in the contraindication reference and the patient is also currently prescribed the drug cited in that rule; the severity is specified by the rule. A laboratory value alert is triggered when a patient's most recent result for a given laboratory test meets or exceeds a threshold defined in the alert threshold configuration, but only when the patient is currently taking one of the drugs listed as relevant for that particular threshold rule; if the patient is on more than one relevant drug from the same rule, each drug produces its own separate alert entry, and the severity is determined by which threshold band the value falls into. A drug-allergy alert is raised whenever a patient is currently prescribed a drug to which they have a documented allergy; every such alert is classified at critical severity with a description noting the specific conflict.

Not every alert reaches the final report. Each patient carries a monitoring level recorded in the ward roster, and the response protocol specifies which severity levels are included under each monitoring level. An alert whose severity falls outside the patient's permitted set must be excluded.

Save the output as `daily_alerts.csv` with columns in this exact order: `patient_id`, `patient_name`, `ward`, `alert_type`, `severity`, `drugs_involved`, `description`, `recommended_action`. Patient names must appear in the format "LastName, FirstName" exactly as recorded in the ward rosters. The `alert_type` field takes one of four exact values: `drug_interaction`, `contraindication`, `lab_alert`, or `drug_allergy`. For drug-drug interaction alerts the `drugs_involved` field lists both drug names in alphabetical order separated by "; " (a semicolon followed by a single space); for all other alert types it contains the single drug name. The `recommended_action` field must use the exact phrasing given in the response protocol for the corresponding severity level.

Rows must be sorted by severity from highest to lowest in the order critical, major, moderate, minor. Within the same severity level sort alphabetically by patient last name then first name. When a single patient has more than one alert at the same severity, further sort those rows alphabetically by alert type.

Once the file is written, provide a summary in your final response stating the total number of alerts generated, the count of alerts for each of the four alert types, the count of alerts at each severity level, and the number of distinct patients who have at least one critical-level alert together with those patients' names listed alphabetically by last name.
