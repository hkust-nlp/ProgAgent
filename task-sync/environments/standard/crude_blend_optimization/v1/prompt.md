You are responsible for generating the daily crude oil blending schedule for a large refinery complex on April 21, 2026. The refinery receives crude oil from storage tanks and pipeline deliveries, blends batches of crude to meet product quality specifications, and delivers the blended product to customers. Your objective is to produce a schedule that maximizes net revenue while satisfying all quality and volume constraints.

Begin by reviewing the configuration files provided in your working directory. One file describes the quality specifications that blended crude must satisfy for each product type and quality tier, covering properties such as API gravity, sulfur content, pour point, and additional laboratory parameters like mercaptan, salt, nickel, and vanadium levels. Another file explains how blend properties are calculated from input crude batches, including the processing loss percentage that reduces the output product volume relative to crude input. A third file lays out the scheduling policy: the order in which demands are processed, how blending units are assigned, which crude sources are eligible, how individual batches are qualified against quality thresholds, how crude is allocated among qualifying batches, how volumes are calculated, and how net revenue is determined.

Separately, a set of laboratory analysis report files contain supplementary quality measurements for each crude batch. These measurements are not available through the data query tools and must be read directly from the report files. The laboratory properties are essential for evaluating whether a batch qualifies for a particular quality tier, especially premium tiers that impose limits on contaminants such as mercaptan, salt content, nickel, and vanadium.

Using the available query tools, retrieve all product demands scheduled for the planning date. Retrieve all storage tanks that are currently available and all pipeline deliveries that are confirmed and scheduled on or before the planning date. For each crude batch referenced by those tanks and deliveries, retrieve its full assay details, including API gravity, sulfur percentage, pour point, and cost per barrel. Also retrieve the online blending units and their throughput capacities and operating costs.

Once you have gathered the data, apply the scheduling policy described in the configuration files. Process demands in the prescribed priority order. For each demand, identify the first eligible blending unit, determine which crude batches individually satisfy every quality specification for the demanded product type and tier, and allocate crude from the highest-priority qualifying batches. Respect all volume limits: do not draw more crude from any source than is available, and do not exceed any unit's maximum throughput. Compute the net revenue for each schedule entry as described in the policy.

After constructing the schedule, save it as `daily_blend_schedule.csv` with the following columns in this exact order: `entry_id`, `demand_id`, `unit_id`, `product_type`, `quality_tier`, `crude_components`, `total_crude_volume_bbl`, `product_volume_bbl`, `net_revenue_usd`. The `entry_id` column is a sequential integer starting from one. The `crude_components` column contains a JSON-encoded object mapping batch identifiers (as strings) to the volume in barrels drawn from that batch, with volumes rounded to two decimal places. The `total_crude_volume_bbl` and `product_volume_bbl` columns are rounded to two decimal places. The `net_revenue_usd` column is rounded to two decimal places.

On top of this, produce a file named `quality_verification.json` containing a JSON array where each element corresponds to one schedule entry and includes the fields `entry_id`, `demand_id`, `product_type`, `quality_tier`, `blend_properties` (an object with the volume-weighted average values of api_gravity, sulfur_pct, pour_point_f, mercaptan_ppm, salt_ptb, nickel_ppm, and vanadium_ppm, each rounded to four decimal places), `spec_limits` (the quality thresholds that applied), and `all_specs_met` (a boolean).

In your final response, report the total net revenue formatted as "Total Net Revenue: $" followed by the amount with commas as thousands separators and two decimal places. Also state the number of demands fulfilled, the total product volume in barrels, and the total crude processed in barrels.
