As part of a management review at an architecture firm, you need to assess the profitability of every project in the portfolio by determining which ones have exceeded their budgets and by how much. This requires pulling together information from several distinct sources and applying the correct adjustments before comparing actual expenditures against planned allocations.

Each project has a designated type that determines an overhead multiplier applied to labor costs. These multipliers are documented in an overhead configuration file available among the records you can access. Similarly, each architect who logs time against a project carries a role-based premium reflecting seniority and specialization; these premiums are recorded in assignment files distributed across multiple documents in various formats.

To compute the true labor expenditure on a given project, retrieve every timesheet entry for that project. For each entry, multiply the logged hours by the architect's base hourly rate (available through the project management system) and by the corresponding role multiplier found in the assignment records. Sum all such products for the project, then scale the result by the overhead multiplier associated with the project's type.

Vendor and subcontractor costs require a different adjustment. Each project carries a retention percentage, found in financial detail records, representing a portion of vendor payments withheld pending final completion. The effective vendor cost for a project equals the sum of all vendor charges for that project, reduced by the retention percentage. Concretely, multiply the raw vendor total by one minus the retention percentage divided by one hundred.

Beyond labor and vendor outlays, each project incurs indirect costs captured in expense log files. These encompass items such as insurance premiums, permit fees, travel, equipment rentals, and similar operational expenditures. Sum every indirect cost entry for each project to obtain the total indirect cost.

A project's budget may have been amended through formally approved change orders. The approved dollar amounts for each change order, recorded in dedicated change order files, should be added to the sum of original budget allocation line items to arrive at the adjusted budget for each project.

With the adjusted budget and total actual cost in hand (total actual cost being the sum of labor, vendor, and indirect components), compute the variance as total actual cost minus adjusted budget. Express the variance as a percentage of the adjusted budget, calculated as the variance amount divided by the adjusted budget times one hundred. Then classify each project according to the variance policy thresholds found in the threshold policy file on record, which defines categories ranging from within budget through significant overrun.

Separately, determine the total amount billed to each project's client by summing all billing invoice amounts associated with that project.

Produce a file called `variance_report.csv` containing one row per project, covering every project in the portfolio regardless of whether it is over or under budget. The rows must be sorted in descending order by variance percentage. The columns must appear in exactly this order: `project_id`, `project_name`, `client_name`, `project_type`, `total_budget`, `adjusted_budget`, `actual_labor_cost`, `actual_vendor_cost`, `actual_indirect_cost`, `total_actual_cost`, `total_billed`, `variance_amount`, `variance_pct`, `classification`. All monetary values and the variance percentage must be rounded to exactly two decimal places.

Once the report file is written, state in your response how many projects were analyzed in total. For each classification category, report the count of projects falling into that category. Then list the three projects with the highest variance percentage, giving for each the project identifier, the project name, the variance percentage formatted to two decimal places, and the variance dollar amount formatted to two decimal places.
