You are tasked with performing a comprehensive departmental budget variance analysis for fiscal year 2025. The organisation maintains its financial data across several systems, and your goal is to correlate information from multiple sources to produce an accurate variance explanation report that flags every department-category combination whose absolute variance exceeds ten percent.

Begin by identifying every department in the organisation and retrieving its base budget allocations for the current fiscal year. These base figures do not, however, tell the full story: throughout the year a series of budget amendments were approved, and the records of those amendments are stored in CSV files whose names begin with "budget_amendment_". Each amendment row specifies a department, a spending category, and a signed dollar amount that must be added to the base allocation to arrive at the adjusted budget for that combination. Sum all amendments that apply to a given department and category, then add the result to the corresponding base budget figure. If no amendment exists for a particular combination, the adjusted budget equals the base allocation unchanged.

Next, gather the actual spending that has been posted to the general ledger. Query every ledger entry for each department, page through all available results, and aggregate the amounts by department and category. These aggregated figures represent the recorded actuals.

For committed but not yet recorded spending, retrieve all purchase orders that carry a status of "Open" for each department. Before summing their amounts, you must apply a vendor-specific discount. Contract files stored as JSON (with names beginning "vendor_contract_") list each vendor along with a field called "committed_discount_pct". Multiply every open purchase-order amount by one minus the corresponding vendor discount rate to obtain the effective committed value. If a vendor does not appear in any contract file, treat the discount as zero.

Forward-looking cost exposure comes from project milestone forecasts. First obtain a list of all projects, then retrieve each project's milestones. Only milestones whose status is "Pending" contribute to the forecast. Each pending milestone's forecast amount must be multiplied by a risk adjustment factor that is recorded in YAML files whose names start with "project_forecast_". Each such file maps project names to a dictionary containing a "risk_adjustment_factor" value. If a project has no entry in any of those files, use a factor of one.

Once you have the four components for every department-category pair that has a budget allocation, compute total exposure as the sum of general-ledger actuals, effective open purchase-order commitments, and adjusted milestone forecasts. The variance amount equals total exposure minus the adjusted budget. The variance percentage equals the variance amount divided by the adjusted budget, multiplied by one hundred and rounded to two decimal places. A line item is flagged whenever the absolute value of its variance percentage exceeds the threshold defined in "variance_policy.yaml" under the key "variance_threshold_pct".

For each department-category pair, also determine the top vendor by total invoiced amount. Query the invoice line items filtered by department, aggregate amounts by vendor, and select the vendor with the highest total. If no invoice line items exist for that combination, record the top vendor as "N/A".

Save the full results as a file called `variance_report.csv` with the following columns in this exact order: `department`, `category`, `adjusted_budget`, `gl_actual`, `po_committed`, `milestone_forecast`, `total_exposure`, `variance_amount`, `variance_pct`, `flagged`, `top_vendor`. The `flagged` column must contain the text "Yes" or "No". Sort rows first by department ascending, then by category ascending. Every numeric value should be rounded to two decimal places.

In your final response, state the total number of department-category line items analysed, the number of items that were flagged, and then list each flagged item showing its department, category, adjusted budget, total exposure, variance percentage, and top vendor.
