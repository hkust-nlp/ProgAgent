The hospital pharmacy department requires a thorough daily medication reconciliation to catch potential dispensing errors before they reach patients. Your role is to examine all electronic medication administration records for the applicable reconciliation period, cross-referencing them against pharmacy dispensation logs, patient allergy databases, and nurse shift assignments, and then compile findings into a standardized report for pharmacist review.

Start by reviewing the configuration and reference files in your working directory to determine the reconciliation date, acceptable dosage deviation thresholds per drug class, error classification definitions, and the medication formulary that maps each medication to its drug class and contraindication profile. The medication order records distributed across batch files in your directory contain the originally prescribed doses, which serve as the baseline for deviation calculations.

For every electronic medication administration record on the reconciliation date, perform the following cross-checks. Look up the medication's drug class through the formulary, then retrieve the patient's documented allergies. If the medication's drug class appears among the patient's allergen classes, this constitutes an allergy conflict. The error severity follows the documented allergy severity level: a severe allergy yields a CRITICAL classification, moderate yields HIGH, and mild yields MEDIUM.

Separately, attempt to locate a matching pharmacy dispensation for each administration record by finding a dispensation with the same patient identifier and medication identifier on the reconciliation date. When no match exists, flag the record as a missing dispensation at HIGH severity. When a matching dispensation is found, calculate the percentage difference between the administered dose and the dispensed dose using the prescribed dose as the denominator, specifically, take the absolute difference between those two doses, divide by the prescribed dose, and multiply by one hundred. If this value exceeds the tolerance percentage specified for the medication's drug class, record it as a dosage mismatch. Classify mismatches exceeding fifty percent as CRITICAL, those between thirty and fifty percent as HIGH, and the rest as MEDIUM.

On top of this, verify that the nurse listed on each administration record was authorized to administer that medication at that time and place. The nurse must have had a shift assignment on the reconciliation date where the assigned ward matches the patient's ward and the administration time falls within the shift window, meaning the time is at or after the shift start and strictly before the shift end, using direct string comparison on the time components in HH:MM:SS format. Any failure of either the ward or time condition constitutes an unauthorized administration at HIGH severity.

Once those checks are complete, compare each administered dose against the prescribed dose from the medication order records. Apply the same percentage deviation formula using the prescribed dose as denominator, and if the result exceeds the drug-class tolerance, flag it as a dose deviation. Deviations over fifty percent are CRITICAL, thirty to fifty percent are HIGH, and the remainder are MEDIUM.

After processing every record, produce two deliverables. Save the detailed findings as `reconciliation_report.csv` containing columns `emar_id`, `patient_id`, `patient_name`, `medication_id`, `medication_name`, `error_type`, `error_severity`, and `details` in that exact order. Each row represents a single detected error, and a given eMAR record may generate multiple rows if it triggers more than one error type. Sort the rows first by severity in the order CRITICAL before HIGH before MEDIUM, and within the same severity level sort by `emar_id` in ascending lexicographic order. Use exactly these error type labels: `ALLERGY_CONFLICT`, `DOSAGE_MISMATCH`, `UNAUTHORIZED_ADMIN`, `MISSING_DISPENSATION`, `DOSE_DEVIATION`. The `details` field should briefly describe the specific issue found, such as the allergen class involved or the numeric deviation percentage.

Also save `error_summary.json` as a JSON object with keys `reconciliation_date` holding the date string, `total_records_reviewed` holding the count of eMAR records checked, `total_errors_found` holding the number of rows in the report, `errors_by_type` as an object mapping each error type to its count, and `errors_by_severity` mapping each severity level to its count.

In your final response, state the reconciliation date, the total number of records reviewed, the total number of errors found, and provide the error counts broken down by type and by severity level.
