You are a phytosanitary compliance analyst tasked with auditing a network of seed storage warehouses for potential contamination events. Several warehouses store seed lots of various crop types across multiple climate-controlled zones, and recent irregularities in environmental monitoring have raised concerns about inventory integrity. Your job is to cross-reference every available data source, flag every seed lot that may have been compromised, and produce a definitive quarantine advisory for the operations team.

Begin by familiarizing yourself with the configuration files that govern this analysis. A YAML file specifies the maximum allowable temperature and humidity for each crop type, which serve as the crop-specific contamination thresholds. A JSON file details the risk-scoring framework: it lists four contamination flag types together with the integer weight each carries, defines tiered action thresholds with minimum scores and corresponding recommended actions, provides a reference date that anchors all temporal checks, and states a grace-period in days for overdue pest treatment calculations. A CSV file maps every zone to its adjacent zones within the same warehouse, where adjacency means the zones are physically neighboring. A markdown protocol document explains how to determine which pest treatment record is current for a given zone and when it should be considered overdue.

Using the available tools, enumerate all warehouses and their zones. For each zone, retrieve the list of seed lots currently stored there. For each lot, obtain its current location details including arrival date, crop type, and variety. The lot manifests distributed across the data files provide supplementary metadata about each lot such as origin farm, grade, and germination rate, but they do not contain current location information, which is only available through the tools.

Four contamination flags must be evaluated for every lot. First, a lot receives a SENSOR_EXCEEDANCE flag if the zone it currently occupies recorded at least one daily maximum temperature or maximum humidity reading that exceeded the crop-specific threshold for that lot's crop type on any date on or after the lot's arrival date. The sensor summary files report daily aggregated statistics per zone and include a general anomaly indicator, but the crop-specific determination must be made by comparing the daily maximum values against the per-crop thresholds from the configuration. Second, a lot receives an ADJACENT_CONTAMINATION flag if any zone adjacent to its current zone, as defined in the adjacency mapping, currently houses at least one lot whose most recent phytosanitary inspection result is FAIL. Use the tools to query lots by their inspection outcomes and then determine those lots' current zones. Third, a lot receives an OVERDUE_TREATMENT flag if the zone it currently occupies has an overdue pest treatment. To determine this, retrieve the treatment schedule for the zone, identify the most recently applied treatment by its application date, and check whether that treatment's next-due date falls before the reference date minus the grace-period specified in the rules file. Fourth, a lot receives a MOVEMENT_EXPOSURE flag if, according to its movement history obtained from the tools, it previously resided in a zone where on any date during its stay in that zone, from its arrival date up to and including the date it was moved out, the daily maximum temperature or humidity exceeded the crop-specific threshold. Movement log files in the data directory record historical movements, but the authoritative per-lot movement history should be retrieved via the tools.

Once all four flags have been evaluated for every lot, compute each flagged lot's risk score by summing the weights of all applicable flags as specified in the rules file. Then assign each lot the recommended action corresponding to the highest tier whose minimum score the lot meets, checking tiers from highest minimum score downward.

Save the results as `quarantine_advisory.csv` with the following columns in this exact order: `lot_id`, `crop_type`, `variety`, `current_warehouse`, `current_zone`, `risk_score`, `contamination_flags`, `recommended_action`. The `contamination_flags` column must contain the applicable flag names separated by a comma and a space, sorted alphabetically. Rows must be sorted by `risk_score` in descending order, with ties broken by `lot_id` in ascending lexicographic order. Only lots with at least one contamination flag should appear in the file.

In your final response, state the total number of lots flagged, the count of lots assigned to each action category, and identify the lot with the highest risk score along with that score.
