You are managing equipment logistics for a film production that has been shooting across multiple stages and exterior locations over the course of several weeks. The production rented a wide variety of gear from different rental houses, each under its own rental agreement specifying a start date, an end date, and a daily rate. Your goal is to analyze the full shooting schedule against every rental agreement, identify pieces of equipment whose last on-set requirement falls well before their contracted return date, and produce a cost-saving roster showing exactly how much money can be recovered by returning qualifying gear early.

Determining whether a piece of equipment qualifies for early return is not a simple date comparison. After the last scene requiring that equipment wraps, a contingency buffer must be added before the gear can safely leave the production. The size of this buffer depends on the equipment's category and on scene-level attributes. A contingency policy document specifies the base buffer in days for each equipment category. On top of the category base, additional buffer days are added if any scene that uses the equipment is flagged as weather-dependent, and further days are added if any of its scenes carries a high priority rating (priority "A"). These scene-level attributes, namely priority and weather-dependency status, are recorded in schedule block files organized as CSVs with columns scene_id, priority, and weather_dependent. The buffer for a given piece of equipment equals the base buffer for its category, plus the weather-dependent addition if at least one of its scenes has weather_dependent set to True, plus the high-priority addition if at least one of its scenes has priority equal to "A". The adjusted return date is then the last needed date plus the total buffer.

Separately, every piece of equipment has undergone periodic condition assessments recorded in condition report files stored as JSON arrays. Each entry contains an equipment_id, an assessment_date, a condition_rating on a one-to-five scale, an inspector name, and free-text notes. To be eligible for early return, the average condition rating across all assessments for that equipment must meet or exceed the minimum threshold documented in the return eligibility rules file. That same rules file specifies a minimum rental period in days; the span from the rental start date to the proposed adjusted return date must be at least that long.

Once the adjusted return date has been computed and eligibility confirmed, the actual savings depend on how many days are recovered and on the daily rate from the rental agreement, minus a fee charged by the rental house for processing an early return. A rate card document, formatted as JSON, maps each rental house name to its early_return_fee_pct. The net savings for a qualifying item equals the number of days saved (contracted end date minus adjusted return date) multiplied by the daily rate, then multiplied by one minus the early return fee percentage. Only items with positive net savings should appear in the output.

To gather the necessary information, retrieve all rental agreements to obtain each equipment's contracted dates, daily rate, and rental house. For each rented item, look up its category and then retrieve the scenes assigned to it so you can determine the last date it is needed on set, which is the latest value of a scene's shoot date plus its duration minus one day. Cross-reference scene identifiers against the schedule block files to determine weather dependency and priority. Read the condition report files to compute each equipment's average condition rating. Read the contingency policy for buffer calculations and the return eligibility rules for the minimum condition threshold and minimum rental period. Finally, consult the rate card for early return fee percentages.

Save the results as `cost_saving_roster.csv` containing exactly these columns in this order: `equipment_id`, `equipment_name`, `category`, `rental_house`, `original_return_date`, `last_needed_date`, `buffer_days`, `adjusted_return_date`, `days_saved`, `daily_rate`, `net_savings`. Include only equipment that qualifies for early return with positive net savings. Sort the rows by `net_savings` in descending order, breaking ties by `equipment_id` in ascending order. Format all dates as YYYY-MM-DD and express `daily_rate` and `net_savings` as numbers with two decimal places.

In your final response, state the total estimated net savings across all qualifying equipment as a dollar amount with two decimal places.
