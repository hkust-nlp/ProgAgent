You are conducting a network adequacy compliance review for a regional health plan that operates across several service areas in California. The central question is whether enrolled members in every service area have adequate geographic access to qualified providers for each covered medical specialty, measured against regulatory distance thresholds that vary by specialty and by the urban, suburban, or rural classification of the area.

Enrolled members are documented in a set of roster files that include each member's identifier, name, mailing address, and the type of coverage plan they hold. These roster files are distributed across your available reference materials and must all be located and consolidated. Provider credential records, also found among the reference materials, detail each provider's board certification status and the date through which that certification remains valid. A separate configuration file specifies the maximum allowable straight-line distance for each specialty under each area classification, and another configuration file establishes the minimum coverage percentage required for compliance in each specialty along with the reference date to be used when evaluating certification validity. An eligibility guidelines document found in the reference materials sets out the precise conditions under which a provider may be counted as serving a particular member.

Meeting these eligibility conditions involves verifying certification currency against the stated reference date, the provider's willingness to accept new patients, the existence of an active contractual arrangement aligned with the member's plan type, and proximity within the prescribed distance limit. When a provider maintains more than one office location for the same specialty, only the location nearest to the member determines the distance. A member is deemed covered for a given specialty if at least one provider satisfying all eligibility conditions can be found within the allowable distance.

Begin by retrieving the complete list of service areas and all covered specialties. For every service area, obtain the members assigned to it, then use the geocoding capability to establish each member's latitude and longitude coordinates. Cross-reference the roster files to determine each member's coverage plan type, which is only available in those files. For every specialty, retrieve the full set of provider office locations together with each provider's patient acceptance status and the plan types under active contract. Merge this information with the credential records from the reference files and apply the eligibility rules to identify, for each member in each service area and specialty, whether at least one qualifying provider falls within the regulatory distance. Distance should be computed using the haversine formula for great-circle distance.

Once all distances and eligibility determinations are complete, produce a file named `deficiency_report.csv` containing one row for each combination of service area and specialty. The columns, in this exact order, must be `service_area_id`, `service_area_name`, `area_type`, `specialty_id`, `specialty_name`, `distance_threshold_miles`, `total_members`, `members_with_access`, `members_without_access`, `coverage_pct`, `required_coverage_pct`, and `compliant`. Express `coverage_pct` and `required_coverage_pct` as numeric values rounded to exactly two decimal places. The `compliant` column takes the value `YES` when coverage meets or exceeds the requirement and `NO` otherwise. Sort the rows by `service_area_id` ascending, breaking ties by `specialty_id` ascending.

In your final response, enumerate every non-compliant service area and specialty pair, stating for each the service area name, the specialty name, the achieved coverage percentage, and the required coverage percentage, so that regulatory follow-up can be directed precisely where the network falls short.
