You are assisting the litigation support team at a law firm representing Acme Corporation in a commercial dispute. During the discovery phase, Acme produced several batches of documents to opposing counsel. A post-production privilege review has revealed concerns that some attorney-client communications and attorney work-product materials may have been inadvertently included in those productions. Your task is to identify every such document and prepare a formal clawback request under Federal Rule of Civil Procedure 26(b)(5)(B).

The production batch manifest files, each in CSV format, contain the records of every document that was sent to opposing counsel. Each manifest entry includes a Bates number, the document type, a source reference code, the page count, the production date, the producing party, and the batch identifier. You should focus exclusively on entries whose document type is classified as an email, since those are the communications that may implicate privilege. The source reference code on email-type entries corresponds to an internal email reference that can be looked up through the available tools.

For each email-type production entry, you need to determine whether any participant in that email holds a role that triggers a potential privilege claim. The privilege review criteria configuration specifies which employee roles are considered triggering roles. You can retrieve email details, including the sender and all recipients, through the tools, and you can look up each participant's role in the employee directory. An email qualifies as potentially privileged if at least one participant, whether as the sender or as any type of recipient, holds one of the designated triggering roles.

Once you have identified emails with privileged participants, you must check the privilege log to determine whether a formal privilege entry exists for that email. A privilege log entry is relevant only if its status appears among the clawback-eligible statuses listed in the privilege criteria configuration, and its privilege type is among the eligible privilege types specified in the clawback rules configuration. If a privilege log entry for the email has a status of waived, or if its privilege type is not among the eligible types, that entry does not support a clawback claim. When an email has multiple privilege log entries, the first qualifying entry encountered should be used.

Separately, the clawback rules configuration specifies a production date cutoff. Only documents whose production date falls on or before that cutoff date should be considered for clawback. Documents produced after the cutoff are outside the scope of this review.

After completing the analysis, save the results as `clawback_request.csv`. The file must contain the following columns in exactly this order: `bates_number`, `source_ref`, `privilege_type`, `privilege_basis`, `reviewing_attorney`, `production_date`, `production_batch`. The `reviewing_attorney` column should contain the full name of the attorney identified as the reviewer in the corresponding privilege log entry. The rows must be sorted in ascending lexicographic order by `bates_number`.

In your final response, state the total number of documents identified for clawback and list every Bates number that should be included in the clawback request, separated by commas.
