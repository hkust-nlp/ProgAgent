You are a logistics analyst responsible for generating a prioritized re-routing plan for high-value parcels that have repeatedly failed delivery. The system tracks every delivery attempt, the customers who expect those parcels, the drivers who attempted delivery, the neighborhoods where deliveries were tried, and each package's physical characteristics and declared monetary value. Your goal is to cross-reference all of these sources, apply the company's rerouting policy, and produce a single definitive CSV file together with a brief textual summary.

Begin by consulting the rerouting policy configuration file to learn the value threshold that separates high-value parcels from ordinary ones, the maximum number of prior attempts beyond which a package is escalated out of this workflow, the weighting scheme used to compute a composite priority score, the score mappings for neighborhood security risk levels and handling complexity codes, the bonus applied when a supervisor has flagged an attempt as urgent, and the normalization caps for declared value and attempt count. Separately, review the handling matrix configuration to understand, for each handling code, what driver certification is mandatory, what vehicle type is required, and what handling note should accompany the shipment.

Identify every package that has at least one failed delivery attempt and no successful delivery on record. Among those, retain only the ones whose declared value meets or exceeds the high-value threshold and whose total number of failed attempts does not exceed the maximum reroute attempts limit defined in the policy. For each qualifying package, determine which neighborhood was involved in its most recent failed attempt, breaking ties on the attempt date by choosing the failed attempt whose attempt identifier comes first alphabetically, because that neighborhood's security profile will feed into the priority calculation. Collect the distinct failure reasons across all of that package's attempts as well.

To compute each package's priority score, normalize its declared value by dividing by the value normalization cap and capping at one, normalize its failed-attempt count similarly using the attempts normalization cap, look up the security risk score for the neighborhood's security level, and look up the handling complexity score for the package's handling code. Multiply each of these four components by its respective weight from the policy and sum them. Then check whether any of that package's delivery attempts carries a supervisor priority flag of "urgent" in the delivery log batch files; if so, add the urgent flag bonus to the score. Round the final priority score to exactly four decimal places.

For the recommended driver assignment, consult the handling matrix to find the certification and vehicle type required by the package's handling code. Then search through all drivers to find those who are currently active, hold the required certification, and whose vehicle type recorded in the driver report files matches the required vehicle type. Among qualifying candidates, select the driver with the highest success rate; if two drivers share the same success rate, prefer the one whose identifier comes first alphabetically. If no driver satisfies both the certification and vehicle type requirements, relax the vehicle constraint and choose the best-certified active driver instead.

Construct a special instructions string for every rerouted package by concatenating three parts separated by " | ". The first part is the handling note from the handling matrix. The second part starts with "Access: " followed by comma-separated access details drawn from the customer access files: include "Gate code: " followed by the code if one exists, include "Buzzer: " followed by the buzzer information if present, and always include "Preferred spot: " followed by the customer's preferred delivery spot. The third part is "Safe hours: " followed by the safe delivery hours window found in the neighborhood bulletin files for the relevant neighborhood.

Once every qualifying package has been scored and assigned a driver, sort them in descending order of priority score with ties broken by package identifier in ascending alphabetical order, and assign sequential rank numbers starting from one. Save the result as `rerouting_list.csv` with the following columns in this exact order: `rank`, `package_id`, `customer_name`, `declared_value`, `priority_score`, `num_failed_attempts`, `failure_reasons` where multiple reasons are joined by "; " in alphabetical order, `neighborhood_name`, `security_level`, `handling_code`, `recommended_driver_id`, `recommended_driver_name`, `special_instructions`.

After writing the file, provide a concise summary stating the total number of packages rerouted, the identifier of the highest-priority package, and the average priority score across all rerouted packages rounded to four decimal places. Format these three facts in your final response exactly as: "Total packages rerouted: N", "Highest priority package: PKGxxxxx", and "Average priority score: x.xxxx".
