You are tasked with performing a full reconciliation of sponsored content delivery across an advertising platform. A set of insertion order contracts in JSON format is available, each specifying what was promised to a particular advertiser: a guaranteed impression count, a list of target demographic segment codes, a demographic compliance threshold, a viewability compliance threshold, a CPM rate, and budget details. The contracts also record each advertiser's tier level. Separately, several configuration documents govern how compliance is assessed. One defines the base delivery tolerance percentage, another provides a penalty schedule organized into shortfall brackets with corresponding multipliers, a third lists minimum measurement sample requirements per ad format for viewability calculations, a fourth maps demographic segment codes to their numeric identifiers, and a fifth specifies per-tier adjustments that are added to the base delivery tolerance.

Your objective is to determine whether every active insertion order has been fulfilled according to its contractual terms, produce a formal compliance certificate, and detail any shortfalls for orders that fall short. For each contract you will need to retrieve the actual delivery data by looking up the order using its reference code, obtaining the campaigns associated with that order, and then gathering impression counts, demographic breakdowns, and viewability measurements for each campaign individually.

Compliance is evaluated across three dimensions. For delivery compliance, sum all impressions served across every campaign under an order and divide by the guaranteed impression count to obtain the delivery rate. The order passes this check if the delivery rate is greater than or equal to one minus the effective tolerance expressed as a fraction, where the effective tolerance equals the base delivery tolerance percentage from the configuration plus the tier-specific adjustment for that advertiser's tier. For demographic compliance, map the target segment codes listed in the contract to their numeric identifiers using the segment mapping, then for each campaign retrieve the per-segment impression breakdown and aggregate across all campaigns: the demographic rate is the sum of impressions delivered to target segments divided by the total impressions across all segments. The order passes this check if the demographic rate meets or exceeds the demographic threshold stated in the contract. For viewability compliance, aggregate viewability across all qualifying campaigns using a weighted average: sum the viewable impressions and divide by the sum of measured impressions. A campaign qualifies for inclusion only if its total measured impressions across all reporting periods meets or exceeds the minimum measurement sample defined for its ad format in the viewability benchmarks configuration. If every campaign under an order falls below its format's minimum, the viewability check is considered passed by default. The order passes this check if its viewability rate meets or exceeds the viewability threshold stated in the contract.

An order is deemed compliant only when all three checks pass. For any order that fails the delivery check, compute the shortfall in impressions as the guaranteed count minus the delivered count, then express this as a percentage of the guaranteed count. Look up the corresponding penalty multiplier from the penalty schedule by finding the bracket where the shortfall percentage is greater than or equal to the bracket minimum and strictly less than the bracket maximum, except for the highest bracket where the upper bound is inclusive. The penalty amount in the configured currency equals the multiplier times the shortfall impressions times the CPM rate from the contract divided by one thousand, rounded to two decimal places. Orders whose delivery check passes incur zero penalty regardless of other outcomes.

Once all orders have been evaluated, produce two deliverable files. The first is `compliance_certificate.json`, containing an object with the keys `certificate_date` set to today's date in YYYY-MM-DD format, `total_orders_evaluated` as an integer, `compliant_count` as an integer, `non_compliant_count` as an integer, `total_penalty_amount` as a number rounded to two decimal places, and `orders` as an array sorted by `order_ref` in ascending lexicographic order. Each element in the orders array must contain the keys `order_ref`, `advertiser_name`, `compliance_status` set to either COMPLIANT or NON-COMPLIANT, `guaranteed_impressions`, `delivered_impressions`, `delivery_rate` rounded to four decimal places, `delivery_status` set to PASS or FAIL, `demographic_rate` rounded to four decimal places, `demographic_threshold`, `demographic_status` set to PASS or FAIL, `viewability_rate` rounded to four decimal places, `viewability_threshold`, `viewability_status` set to PASS or FAIL, and `penalty_amount` rounded to two decimal places.

The second deliverable is `shortfall_report.csv` with one row per non-compliant order, sorted by `order_ref` ascending. Its columns must be `order_ref`, `advertiser_name`, `failed_checks` as a semicolon-separated list of which checks failed using the labels delivery and demographic and viewability, `guaranteed_impressions`, `delivered_impressions`, `delivery_rate` rounded to four decimal places, `demographic_rate` rounded to four decimal places, `viewability_rate` rounded to four decimal places, and `penalty_amount` rounded to two decimal places.

In your final response, state the total number of orders evaluated, how many were compliant, how many were non-compliant, and the total penalty amount formatted to two decimal places.
