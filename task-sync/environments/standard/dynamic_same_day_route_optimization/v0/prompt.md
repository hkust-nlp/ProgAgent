Your organization operates a same-day delivery service spanning several urban and suburban zones in a metropolitan area. The dispatch cycle runs every fifteen minutes, and it is time to produce the next driver-assignment manifest based on current conditions. You have access to the fleet tracking system through a set of query tools, and you also have a collection of reference documents covering zone geography, vehicle specifications, service-level agreements, and operational dispatch rules.

Start by assessing the overall dispatch landscape: determine how many pending orders and available couriers exist in each delivery zone. Then retrieve the detailed list of available couriers zone by zone, noting each courier's vehicle type, current position, and remaining cargo capacity. Collect every pending order as well, paying attention to each order's delivery destination, weight, parcel count, and priority classification. For every pending order, you will also need the customer's membership tier, which can be obtained through the customer information lookup.

Each order has a handling classification that restricts which vehicle types may carry it. These classifications are recorded in batch data files distributed across your reference documents. You will need to cross-reference each order's handling classification against the vehicle compatibility rules to filter eligible couriers, and then consult the service-level agreement thresholds that pair customer tiers with order priorities to determine the maximum acceptable delivery window in minutes. The zone configuration document describes how zones relate to one another, which are neighbors, and what time penalty applies when a courier crosses from one zone into another. A separate policy document lays out the exact sequencing and tie-breaking logic for assigning couriers to orders, as well as how to handle orders that no courier can feasibly serve.

To estimate how long a given courier would take to deliver a particular order, query the traffic estimation system for the travel time between the courier's current zone and the order's delivery zone. That figure must then be adjusted by the courier's vehicle speed characteristic found in the vehicle specifications and any cross-zone transfer penalty before being compared against the applicable service-level deadline.

Save the completed manifest as `assignment_manifest.csv`. The file must contain exactly these columns in this order: `courier_id`, `courier_name`, `order_id`, `delivery_zone_id`, `estimated_delivery_min`, `priority`, `handling_code`, `sla_deadline_min`. Express estimated delivery times rounded to one decimal place. Rows should be sorted first by priority in descending urgency, meaning urgent before high, high before standard, and standard before low, and within the same priority level by ascending order identifier.

Once the manifest is written, state in your response the total number of orders that were successfully assigned to a courier, the number of distinct couriers utilized, the count of orders that had to be marked as unassigned, and the average estimated delivery time across all assigned orders rounded to one decimal place.
