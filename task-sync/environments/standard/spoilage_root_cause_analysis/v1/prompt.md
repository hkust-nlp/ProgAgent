You have been brought in to investigate a recurring spoilage problem affecting leafy greens across a regional cold-chain distribution network. Multiple farms ship harvested batches of spinach, kale, romaine lettuce, arugula, swiss chard, and butter lettuce through refrigerated transport to a set of warehouses, where the produce is held before onward distribution. Quality inspectors evaluate each batch after it arrives and record the percentage of product that has spoiled along with observed defect types. Your job is to identify every batch that has experienced unacceptable spoilage, determine the root cause for each one, and produce actionable corrective recommendations.

Begin by consulting the analysis protocol document and the spoilage classification configuration to learn how a batch is flagged for investigation and how severity levels are assigned. The classification configuration also specifies the exact spoilage percentage threshold that separates acceptable from flagged batches. Once you know that threshold, use it to retrieve all inspections whose spoilage percentage meets or exceeds it. Those are the batches you must analyse.

For every flagged batch you need to gather several pieces of information. First, retrieve the batch details to learn the crop type, the originating farm, the harvested quantity in kilograms, and the harvest timestamp. Next, retrieve the transport legs for that batch and, for each leg, pull the temperature readings recorded by sensors during transit. You will also need the warehouse environment records showing humidity and temperature at each check. Finally, consult the field condition reports stored as CSV files to find the field temperature and rainfall at the time of harvest for the batch in question.

The cold-chain thresholds configuration file contains crop-specific maximum acceptable values for transport temperature, warehouse humidity, precooling delay, field temperature at harvest, and rainfall. Using those thresholds, classify each flagged batch into exactly one root cause by applying the following rules in strict order and assigning the first one that matches. If the maximum temperature observed across all transport legs exceeds the crop-specific maximum transport temperature, the root cause is "transport_temperature_excursion". Otherwise, if the maximum humidity across all warehouse checks exceeds the crop-specific maximum warehouse humidity, the root cause is "warehouse_humidity_violation". Otherwise, if the elapsed time in hours between the batch harvest datetime and the earliest warehouse check datetime exceeds the crop-specific maximum precooling delay, the root cause is "delayed_precooling". Otherwise, if the field temperature at harvest exceeds the crop-specific maximum field temperature or the rainfall in the preceding twenty-four hours exceeds the crop-specific maximum rainfall, the root cause is "adverse_field_conditions". If none of those conditions are met, assign "unknown".

Determine the severity of each flagged batch by looking up its spoilage percentage in the spoilage classification ranges. The corrective action guidelines document lists the recommended actions and priority level for each root cause category.

Once the analysis is complete, save a file called `root_cause_analysis.csv` containing one row per flagged batch. The columns must appear in exactly this order: `batch_id`, `crop_type`, `farm_origin`, `spoilage_pct`, `severity`, `root_cause`. Rows must be sorted by `spoilage_pct` in descending order. The `spoilage_pct` values should reflect the original inspection figures without rounding.

Separately, save a file called `corrective_actions.json`. This file must be a JSON object whose keys are the root cause category names that appear among the flagged batches. Each key maps to an object with four fields: `batch_count` giving the integer number of flagged batches with that root cause, `total_affected_quantity_kg` giving the sum of the harvested quantities of those batches rounded to one decimal place, `recommended_actions` as a list of strings drawn from the guidelines document, and `priority` as either "HIGH" or "MEDIUM" matching the guidelines.

In your final response, state the total number of flagged batches in the exact format "Total flagged batches: N" where N is the count. Then, for each root cause category present, state the category name, the number of affected batches, and the total affected quantity. Conclude by identifying the single root cause category responsible for the highest total affected quantity and state it in the format "Highest impact root cause: CAUSE (QUANTITY kg)" where CAUSE is the category name and QUANTITY is the total kilograms to one decimal place.
