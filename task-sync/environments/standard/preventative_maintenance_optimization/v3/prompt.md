You are a property maintenance analyst charged with producing a prioritized quarterly maintenance calendar for the upcoming third quarter of 2026, spanning July through September. The property portfolio encompasses numerous buildings organized into maintenance zones, each housing various appliances that range from climate control systems to elevators to safety equipment, all tracked in a central registry accessible through data queries.

Your environment contains a YAML scoring configuration that establishes the methodology for ranking appliances by maintenance priority. Five evaluation dimensions carry specific weights that together sum to one: warranty urgency, condition deficit, tenant request frequency, maintenance gap, and criticality. The priority score for each appliance is the weighted sum of these five component scores, each scaled between zero and one hundred.

To compute warranty urgency, determine whether the appliance's warranty expires on or before the last day of the target quarter. If so, count the days remaining from the quarter's start date to the warranty expiration, capping this count at the warning-day horizon found in the configuration's normalization section. The urgency score equals one minus the ratio of capped remaining days to the warning horizon, multiplied by one hundred. An appliance whose warranty extends beyond the quarter's end receives a zero for this component.

Condition deficit draws on inspection data distributed across zone-level CSV files that record condition scores for appliances surveyed in each zone. Subtract the appliance's recorded condition score from one hundred to obtain the deficit. Where no inspection record exists for a particular appliance, substitute the default condition score provided in the configuration's normalization section.

For request frequency, tally all tenant repair requests that share both the appliance's building and its appliance category. Divide this count by the maximum request count from the configuration, cap the ratio at one, and scale to one hundred.

Maintenance gap measures the elapsed time between the appliance's most recent work order and the quarter's start date. Divide this interval in days by the maximum gap parameter from the configuration, cap at one, and scale to one hundred. An appliance with no recorded work orders receives the maximum score of one hundred.

The criticality component converts the appliance's criticality rating directly by multiplying the integer rating by twenty.

After computing priority scores for every appliance in the portfolio, discard any whose score falls below the minimum threshold stated in the scheduling section of the configuration. The surviving appliances form the candidate pool for the quarter.

Each candidate requires a vendor assignment. Consider only vendors whose specialty matches the appliance's category and who are marked as active. A CSV rate schedule lists seasonal multipliers for every vendor across all four quarters of the year; look up the multiplier corresponding to the third quarter. Multiply the vendor's base hourly rate by this seasonal multiplier to arrive at the effective hourly rate. A separate YAML reference specifies estimated service hours for each appliance category; multiply the effective rate by these hours and round the result to two decimal places to get the estimated cost. Among all eligible vendors for a given appliance, select the one with the lowest estimated cost. If two vendors tie on cost, prefer the one with the higher reliability score. If they still tie, prefer the lower vendor identifier.

A JSON document defines monthly budget caps for each month of the quarter and a maximum number of items that can be scheduled per month. Process candidates in descending order of priority score, breaking ties by ascending appliance identifier. Assign each candidate to the earliest month, starting with July, whose remaining budget can absorb the estimated cost and whose item count has not yet reached the monthly limit. Any candidate that cannot fit into any month is dropped from the calendar.

Save the resulting calendar as `maintenance_calendar.csv` containing exactly these columns in this order: `month`, `appliance_id`, `building_id`, `category`, `priority_score`, `assigned_vendor_id`, `estimated_cost`. Format both `priority_score` and `estimated_cost` to exactly two decimal places. Sort the rows by `month` ascending, then by `priority_score` descending within each month; where scores are identical, order by `appliance_id` ascending.

When you have finished, report three summary figures in your final response: the total number of maintenance tasks scheduled across the quarter, the total estimated cost for all scheduled items rounded to two decimal places, and the appliance identifier that achieved the highest priority score together with that score rounded to two decimal places.
