Every day before the outbound trucks depart, the sorting facility must identify packages that have been routed to the wrong sort lane. You are responsible for producing a comprehensive re-sort list that flags every mis-sorted package found across all stations, along with cost-avoidance estimates that quantify the savings from catching these errors before shipment.

To determine whether a package is mis-sorted, take the first five digits of its destination postal code and look up the corresponding zone in the postal-code-to-zone mapping provided among your reference files. Then consult the lane configuration to find which sort lane that zone should be routed to. If the package's currently assigned lane does not match the correct lane for its zone, that package is mis-sorted and must appear on the re-sort list.

For every package identified as mis-sorted, you must also assess whether it exhibits a weight discrepancy or a dimension discrepancy. A weight discrepancy exists when the absolute difference between the declared weight and the measured weight exceeds the threshold specified in the sorting policy document. Similarly, a dimension discrepancy exists when any single axis among length, width, or height shows an absolute difference between declared and scanned values that exceeds the dimensional tolerance defined in the same policy document. Record each of these as True or False for the affected package.

The cost avoidance for each mis-sorted package is calculated using the formula described in the sorting policy document. You will need the package's shipping class and its destination zone to look up the base cost from the cost avoidance rates reference file. You will also need the customer tier for that package, which can be found across the shipment batch manifest files. Apply the tier multiplier specified in the policy document to the base cost to arrive at the final cost avoidance value, rounded to exactly two decimal places.

Once you have gathered all the information, save the results as `re_sort_list.csv`. This file must contain columns named exactly `package_id`, `tracking_number`, `station_id`, `assigned_lane`, `correct_lane`, `destination_zone`, `shipping_class`, `customer_tier`, `weight_discrepancy`, `dimension_discrepancy`, and `cost_avoidance`. The rows must be sorted by `cost_avoidance` in descending order, with ties broken by `package_id` in ascending order.

In your final response, state the total number of mis-sorted packages found, the total estimated cost avoidance across all mis-sorted packages formatted to exactly two decimal places, and the station identifier that had the highest number of mis-sorted packages. If multiple stations are tied for the highest count, report the one whose identifier comes first alphabetically.
