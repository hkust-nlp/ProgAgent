You are assisting a feedlot herd manager who needs a daily quarantine watchlist identifying cattle at elevated risk for bovine respiratory disease outbreaks. The operation tracks animals through environmental monitoring, vaccination records, movement logs, and veterinary treatment histories, and your job is to pull all of these threads together into a single actionable report.

Begin by reading the configuration files that govern how risk is assessed. A YAML file describes the environmental sensor thresholds and the weights assigned to each risk category, as well as the quarantine score threshold, the window in days for considering recent movements, the window for recent treatments, and the number of days after which a vaccine booster is considered overdue. A JSON file defines the vaccination protocol: the list of required vaccines, how soon after arrival each must be given, the booster interval, the priority level of each vaccine, and the point values assigned when a critical vaccine is missing, a high-priority vaccine is missing, or a booster is overdue. A CSV file maps every pen identifier to its parent barn. A policy document explains in detail how the composite risk score is calculated, what labels to use for each risk factor, and the rules for sorting and formatting the final watchlist.

Once you understand the scoring framework, gather the environmental picture. Retrieve the list of barns from the sensor system, then pull the sensor readings for each barn for the date 2026-04-22. For every hourly reading, check whether any of the five environmental threshold types are breached: temperature exceeding the high limit, temperature falling below the low limit, humidity above the high limit, ammonia concentration above the high limit, or airflow dropping below the low limit. Record which breach types occurred in each barn across the full day.

Next, enumerate every animal in the herd by paging through the cattle listing. For each animal, determine which barn it resides in using the pen-to-barn mapping. Then retrieve its vaccination history, its movement history, and its treatment records. Separately, read all of the daily health observation batch files found alongside the configuration files. These observation files come in several formats and contain per-animal symptom notes; any animal whose symptom field is anything other than "none" should be flagged as exhibiting observation symptoms.

Compute the composite risk score for each animal following the policy document's formula. The environmental component awards a fraction of its weight for each distinct breach type detected in the animal's barn. The vaccination component checks every required vaccine from the protocol: if the vaccine was never administered, apply the missing-vaccine penalty corresponding to its priority level; if it was administered but the booster interval has elapsed since the most recent dose, apply the overdue-booster penalty; only the highest applicable penalty per vaccine counts. The movement component adds its full weight if the animal was transferred between pens within the recent-move window. The treatment component adds its full weight if the animal has any respiratory-related diagnosis within the recent-treatment window, where respiratory diagnoses include bovine respiratory disease, pneumonia, shipping fever, upper respiratory infection, and pleuritis. The observation component adds its full weight when symptoms are flagged. Floor the final score to an integer.

Any animal whose integer score meets or exceeds the quarantine threshold belongs on the watchlist. Save the watchlist as `quarantine_watchlist.csv` with exactly these columns in this order: `tag_number`, `pen_id`, `barn_id`, `risk_score`, `risk_factors`. The risk factors column must contain the applicable risk factor labels joined by semicolons with no spaces, sorted alphabetically. Sort rows by risk score descending; break ties by tag number ascending lexicographically.

In your final response, state the total number of animals placed on the quarantine watchlist, identify the highest-risk animal by tag number and score, and confirm that the file has been saved as `quarantine_watchlist.csv`.
