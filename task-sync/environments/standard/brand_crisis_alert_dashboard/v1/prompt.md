You are tasked with analyzing social media activity across a portfolio of monitored brands to identify those experiencing emerging crises that warrant immediate attention from the PR team. The necessary data is distributed across several files and a set of tools, and you must combine information from both sources to arrive at correct results.

Start by surveying the available data files. You will find multiple CSV files containing recent daily post-volume figures broken down by brand, date, and platform. A separate CSV provides each brand's historical average daily post volume, serving as the baseline for normal activity. A YAML configuration file specifies the thresholds that determine whether a brand qualifies as being in crisis, a JSON file holds the weights for each component of the crisis severity score, a text file describes the exact scoring formula to apply, and another CSV maps each brand to a tier classification and its corresponding priority multiplier.

To determine whether a brand is experiencing a crisis, first compute a spike ratio for each brand by dividing its recent average daily volume (the total post count across all platforms and dates in the monitoring reports, divided by the number of distinct dates) by its baseline average daily volume from the reference file. A brand qualifies for the crisis dashboard only when three conditions are simultaneously satisfied: its spike ratio meets or exceeds the volume spike multiplier specified in the crisis configuration, its average comment sentiment score (obtained through the tools) falls strictly below the sentiment threshold in the configuration, and the count of product mentions carrying a critical severity tag (also obtained through the tools) meets or exceeds the minimum critical mentions threshold. All three conditions must hold.

For every brand whose post volumes indicate a spike, use the available tools to retrieve its aggregated sentiment summary, which reports the mean sentiment across all comments on that brand's posts. For brands that also pass the sentiment filter, retrieve their product mention records to tally how many are tagged as critical and to identify which specific product accumulates the most critical mentions. Investigate influencer involvement for each qualifying brand by fetching posts authored by influencers about that brand, then looking up each influencer's account details to determine verification status. When computing the influencer component of the score, count only the number of distinct verified influencer accounts.

Apply the scoring formula exactly as described in the formula file. The formula combines four bounded and weighted components derived from the spike ratio, the absolute value of the average sentiment score, the count of distinct verified influencers, and the ratio of critical product mentions to total product mentions. Multiply the resulting crisis score by the brand's tier-based priority multiplier to obtain the final score, rounding both the crisis score and the final score to two decimal places. Assign an alert level to each brand based on where its final score falls relative to the thresholds defined in the crisis configuration file.

Save the completed dashboard to a file named `crisis_dashboard.csv` with the following columns in exactly this order: `priority_rank`, `brand_name`, `brand_id`, `crisis_score`, `final_score`, `alert_level`, `spike_ratio`, `avg_sentiment`, `verified_influencer_count`, `critical_mention_count`, `primary_product`. The `primary_product` column should contain the product name with the highest count of critical mentions for that brand, with ties broken alphabetically. Sort rows by `final_score` in descending order, breaking ties alphabetically by `brand_name`. The `priority_rank` column must contain sequential integers starting from one. Round `crisis_score`, `final_score`, `spike_ratio`, and `avg_sentiment` to exactly two decimal places.

In your final response, state the total number of brands that qualified for the crisis dashboard and list the top three brands by final score, including each brand's name, final score, and alert level.
