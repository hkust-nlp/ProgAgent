Your institution's Office of Sponsored Programs needs an urgent assessment of grant awards that are at risk of forfeiting unspent funds. Federal and private sponsors generally do not permit principal investigators to retain balances past the award's end date unless the sponsor has explicitly approved a carryover of remaining funds. The overarching goal is to identify every active award whose effective expiration falls within a ninety-day window of the current reporting date and whose remaining budget has not been fully exhausted, then rank those awards by urgency so that project directors can take action before the deadlines lapse.

Begin by consulting the configuration files that govern this analysis. A YAML configuration file specifies the reporting reference date, the size of the look-ahead window in days, and the precise column layout and sort order expected in the final deliverable. A separate JSON file defines the priority-tier classification scheme: each tier has a name, a maximum number of days to expiration, and a minimum remaining-balance percentage threshold, and tiers are evaluated in the order they appear so that the first matching tier is assigned. A third YAML file describes the institution's indirect cost policy, including which cost base type to use when looking up the negotiated rate, which expenditure categories are excluded from the indirect cost base, and how the applicable fiscal year is determined from the reference date (using the fiscal-year start month specified in that file).

With those parameters in hand, retrieve all active awards from the grants system, page by page. For each active award whose original end date falls within the look-ahead window, retrieve its award modification history. Some awards may have received a no-cost extension from the sponsor, which shifts the effective expiration to the new end date recorded in that modification. If the latest no-cost-extension date pushes the award's effective end beyond the look-ahead window, that award is no longer at risk and should be excluded. Awards that remain within the window after accounting for extensions are candidates for the report.

Next, review the grant memoranda files stored across the available batch text files. Each memorandum block is headed by a grant identifier and contains administrative notes. If a memorandum indicates that carryover of unspent funds has been approved by the sponsor, that award is exempt from the use-it-or-lose-it concern and must be dropped from the candidate list regardless of its remaining balance.

For every award that survives both filters, compute its total awarded amount by summing the original budget with all supplement and reduction modifications. Retrieve the expenditure ledger for the award and total the direct costs. Then determine the indirect cost charges: subtract expenditures in the excluded categories from total direct costs to arrive at the modified direct-cost base, look up the negotiated rate for the award's department in the fiscal year derived from the reference date using the base type specified in the policy, and multiply the base by that rate. Also sum any pending purchase-order obligations recorded in the obligation batch CSV files found among the data files, as these encumbered amounts have not yet posted to the ledger but will consume budget before the award closes. The remaining balance is the total awarded amount minus direct expenditures, minus indirect cost charges, minus pending obligations. Express the remaining percentage as remaining balance divided by total awarded, multiplied by one hundred.

Determine the number of calendar days between the reference date and the award's effective expiration. Assign each award a priority tier by checking the tier rules in order and selecting the first tier whose day and percentage thresholds are both satisfied. Once all awards have been processed, sort the full list first by priority tier in the order specified in the tier configuration, then by days to expiration in ascending order within each tier.

Each award's project director has contact information spread across the batch JSON contact files. Look up the director's e-mail address so it can appear in the output alongside the director's name.

Save the final report as `use_it_or_lose_it_report.csv`. The file must contain exactly these columns in this order: `grant_id`, `title`, `project_director`, `director_email`, `department`, `sponsor`, `total_awarded`, `total_spent`, `idc_charges`, `pending_obligations`, `remaining_balance`, `remaining_pct`, `days_to_expiration`, `priority_tier`. All monetary values and the remaining percentage must be rounded to two decimal places. The `total_spent` column reflects the sum of direct expenditures only; indirect cost charges and pending obligations appear in their own dedicated columns. Rows must appear in the prescribed sort order.

After writing the report, provide a brief summary stating how many grants appear on the list, how many fall into each priority tier, and the aggregate remaining balance across all listed awards.
