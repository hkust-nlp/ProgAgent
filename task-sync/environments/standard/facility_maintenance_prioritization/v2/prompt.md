You are tasked with producing a comprehensive, ranked work order list for all branch facilities that require maintenance attention during the upcoming quarter. The organization operates numerous branches across several regions, each housing various pieces of equipment ranging from HVAC units and elevators to electrical panels and fire suppression systems. Your job is to identify every piece of equipment that qualifies for a work order, calculate its priority score according to the scoring methodology laid out in the configuration and policy documents found alongside the data files, and produce a single output file containing the final ranked list.

Begin by examining the configuration file named `priority_config.yaml`, which specifies the scoring weights, the quarter date range, and the exact output format including the file name and column structure you must follow. There is also a policy document named `maintenance_policy.md` that explains the eligibility rules for generating work orders, the step-by-step priority score calculation procedure, the vendor assignment logic, the work order ID format, and the tie-breaking rules. A mapping file named `equipment_specialty_map.json` provides the correspondence between equipment types and vendor specialties, which you will need for vendor assignment. Read all three of these documents carefully before proceeding, as they govern every aspect of the task.

To determine which equipment items qualify for work orders, you must cross-reference multiple data sources. Complaint ticket data is available in CSV files that contain open and in-progress customer complaints along with the equipment each complaint is linked to. Service log summaries are provided in text files that document recent maintenance activities including whether follow-up work was flagged. Maintenance schedule data is available in YAML files that list upcoming and overdue preventative maintenance entries for equipment. All of these files should be read and their contents integrated with the information you retrieve through the available query tools.

For every branch, retrieve its equipment roster using the tools at your disposal, then for each piece of equipment, determine whether it meets any of the three eligibility conditions described in the policy: an overdue preventative maintenance schedule falling on or before the quarter end date, at least one open or in-progress complaint ticket linked to it, or a service log with a follow-up flag within the past twelve months measured from the quarter end date. Equipment meeting none of these conditions should be excluded entirely.

Once the eligible set is established, compute the priority score for each item by following the procedure in the policy document exactly, applying the numerical parameters from the configuration file. You will need to retrieve equipment installation dates to evaluate the age bonus, query service log counts within the relevant date range to detect repeat failures, and look up vendor information by specialty to determine both the assignment and whether a response-time penalty applies. The final score for each work order must be rounded to two decimal places.

After scoring, sort all work orders in descending order of priority score. Where scores are identical, break ties first by branch ID in ascending alphabetical order, then by equipment ID in ascending alphabetical order. Assign sequential work order IDs in the format specified by the policy, starting from the first item in the sorted list.

Save the complete ranked list as `ranked_work_orders.csv` with exactly the columns specified in the configuration file, in the order listed there: `rank`, `work_order_id`, `branch_id`, `branch_name`, `equipment_id`, `equipment_type`, `issue_summary`, `priority_score`, `assigned_vendor_id`, `vendor_name`, `estimated_cost`, `target_completion_date`. The `issue_summary` column should contain a semicolon-separated description of which eligibility conditions the equipment met, using the phrases "Overdue maintenance" for overdue schedules, "Complaints (N open/in-progress)" where N is the count of qualifying complaints for that equipment, and "Follow-up needed from service" for flagged service logs. The `estimated_cost` should be the highest estimated cost among the equipment's maintenance schedules, or zero if none exist. The `target_completion_date` for every row is the quarter end date.

Once the file is written, respond with a summary stating the total number of work orders generated and identifying the highest-priority work order by its ID.
