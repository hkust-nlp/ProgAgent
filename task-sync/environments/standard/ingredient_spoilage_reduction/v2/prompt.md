You are the inventory analyst for a busy commercial kitchen that needs to minimize ingredient waste. Your job is to produce a single, authoritative prioritized list telling kitchen staff exactly which batches to use first, which to discard, and which to keep an eye on. Every batch currently on hand must appear in this list, scored and ranked by spoilage risk.

Begin by locating the YAML configuration file that governs how spoilage risk is calculated. It contains a reference date that anchors all freshness computations, a set of numerical coefficients used in the scoring formulas, and threshold brackets that map effective remaining shelf life to recommended actions. Read every formula description in that file carefully, because the coefficients, penalties, and multiplier it defines must be applied exactly as specified. There is also a JSON file describing the fridge and storage zones in the kitchen, including each zone's identifier and the ingredient categories it stores.

Current on-hand inventory is recorded across multiple JSON snapshot files. Each entry identifies an ingredient by its numeric ID, the batch code that ties it back to a supplier delivery, the storage zone the batch currently sits in, and the quantity remaining. Collect every entry from every snapshot file; this is the full set of batches that must be scored.

Supplier delivery observation reports are spread across several plain-text files. Each report lists batches that were inspected upon arrival. Some entries carry a condition flag, a line containing the phrase "CONDITION FLAG" that indicates the batch arrived in suboptimal condition such as warm temperature, damaged packaging, or a delayed cold chain. Record which batch codes are flagged, because each flagged batch incurs a fixed penalty to its effective remaining shelf life, the exact number of days specified as the condition flag penalty in the configuration.

For every unique ingredient appearing in the on-hand inventory, retrieve the full ingredient record through the available lookup capability. You will need the ingredient's shelf life in days and its maximum acceptable storage temperature. Separately, for every batch in the inventory, look up the delivery record using the batch code to obtain the delivery date. Compute the number of days elapsed between the delivery date and the reference date, then subtract that from the shelf life to get the base remaining days.

Temperature logs are available per storage zone per day. For each zone that houses at least one in-stock batch, pull the temperature readings for the three days leading up to and including the reference date. Average all readings across those days to obtain the zone's three-day average temperature. If this average exceeds the ingredient's maximum storage temperature, compute the excess and multiply it by the temperature penalty coefficient from the configuration. That product is the temperature penalty in days. Subtract it from the base remaining days along with any condition-flag penalty to arrive at the effective remaining days for the batch.

Once you have the effective remaining days for a batch, determine its historical waste rate. For each ingredient, retrieve all waste log entries and sum the total quantity wasted. Also retrieve all delivery records for that ingredient and sum the total quantity delivered. The waste rate is the ratio of wasted to delivered, or zero if no deliveries exist. Then apply the spoilage risk score formula: divide one by the effective remaining days, floored at 0.1 to avoid division by zero, and multiply by the quantity one plus the waste rate times the waste rate multiplier from the configuration.

Assign a recommended action to each batch based on the action thresholds in the configuration. A batch whose effective remaining days is at or below zero should be labeled DISCARD. A batch whose effective remaining days is above zero but at or below the USE_IMMEDIATELY threshold should be labeled USE_IMMEDIATELY. A batch at or below the USE_SOON threshold gets USE_SOON. Everything else is MONITOR. These labels must match exactly in uppercase with underscores.

Sort all batches by spoilage risk score in descending order so that the most urgent items come first. When two batches share the same score to four decimal places, break the tie alphabetically by ingredient name in ascending order. Assign an integer rank starting at one.

Save the final list as `priority_list.csv` with exactly these columns in this order: `rank`, `ingredient_name`, `batch_code`, `category`, `delivery_date`, `effective_remaining_days`, `spoilage_risk_score`, `recommended_action`. Round effective remaining days to one decimal place and spoilage risk score to four decimal places.

In your final response, summarize the five highest-risk batches by stating each one's rank, ingredient name, batch code, effective remaining days, risk score, and recommended action. After that, state how many batches fall into each action category, for example DISCARD: 4, USE_IMMEDIATELY: 7, and so on for every category that has at least one batch. Use the exact action label names and their counts.
