You are responsible for producing a complete, conflict-free weekly room-allocation schedule for a school. Every class section offered this term must be assigned to a specific room during each of its weekly meeting periods, and no room may host more than one class in the same time slot. Likewise, no teacher may be double-booked: because each class has exactly one assigned teacher, a teacher who appears in two classes cannot have those classes scheduled in the same day-and-period combination.

The school week runs from Monday through Friday. The exact number of periods per day and the duration of each period in minutes are recorded in the scheduling policy file found among your available files. Each class's required number of weekly meetings is not stored directly; instead, you must look up the minimum weekly instructional minutes for the class's subject and grade level in the instructional-minutes reference file, then divide by the per-period duration (rounding up to a whole number of periods). That derived count is how many times each class must appear in the final schedule.

Teacher information, including each teacher's department, maximum allowed periods per day, and maximum allowed periods per week, is available through the provided query tools. For every teacher you must also retrieve their individual subject certifications through the dedicated certification lookup; a teacher may hold primary or secondary certification in one or more subjects. Separately, teacher availability constraints are recorded in a set of CSV files that list the specific day-and-period combinations during which a teacher is unavailable. Any slot not listed in those files is considered available. The schedule must never place a class in a slot where its teacher is marked unavailable, and it must respect both the daily and weekly period caps for each teacher.

Class records, accessible via the query tools, provide the class name, subject, grade level, assigned teacher, and student enrollment count. Room records similarly give each room's name, seating capacity, type, building, and floor. The room's seating capacity must be at least as large as the enrollment of any class placed in it. Beyond raw capacity, certain subjects demand specialist equipment. A JSON reference file maps every subject to the list of equipment items it requires, while a collection of YAML manifest files itemizes the equipment actually installed in each room. A class may only be placed in a room whose equipment list contains every item the class's subject requires.

There are additional priority rules documented in a plain-text rules file. Specialist rooms such as labs, studios, and gymnasia are reserved exclusively for classes whose subjects need specialist equipment; classes in subjects that require no special equipment must not occupy those rooms even if they happen to have enough seats. When more than one room satisfies a class's needs, you should choose the room whose surplus capacity over the class enrollment is the smallest non-negative value, breaking ties by preferring the room with the lower numeric room identifier. Classes with larger enrollments should be given scheduling priority so they are matched to appropriately sized rooms before smaller classes consume those rooms.

Once you have gathered all necessary information from the query tools and the reference files, construct a weekly timetable and save it as `weekly_schedule.csv`. The file must contain exactly these columns in this order: `day`, `period`, `class_id`, `class_name`, `room_id`, `room_name`, `teacher_id`, `teacher_name`. Sort the rows first by day of the week in calendar order starting from Monday, then by period number in ascending order, then by class identifier in ascending order.

After writing the schedule file, include in your final response a single summary line in exactly this format, substituting the correct totals from the schedule you produced: "Scheduling Summary: X classes across Y periods using Z rooms" where X is the count of distinct classes scheduled, Y is the total number of individual period assignments in the file, and Z is the count of distinct rooms that appear at least once in the schedule.
