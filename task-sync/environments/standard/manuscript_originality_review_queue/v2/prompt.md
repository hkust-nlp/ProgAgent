You are an editorial integrity analyst responsible for screening every manuscript currently pending originality review. Your goal is to compute a plagiarism risk score for each pending submission, flag those that exceed the established threshold, and produce two deliverable files along with a concise textual summary of your findings.

Begin by locating and reading the scoring configuration, which specifies the numeric weights assigned to each similarity component (text similarity, citation overlap, and structural similarity), the flagging threshold, retraction-related penalty values, the maximum number of top-matching articles to consider per manuscript, and the discount factor applied when a matched article has been declared as a source by the authors. A separate configuration file provides discipline-specific adjustment multipliers that modify the composite score depending on the manuscript's field of study. An editorial policy document further describes the precise computation sequence, severity classification rules, and the ordering requirements for the final reports.

Once you understand the scoring rules, retrieve every manuscript that is currently awaiting originality review. For each such manuscript, obtain its detailed metadata, including its list of authors and its discipline. Each pending submission also has a corresponding text file whose header contains, among other fields, a declared-sources line listing any article identifiers the authors have openly cited as prior related work; if that line reads NONE, no sources were declared. You must read this declared-sources information because it directly affects the risk calculation.

For each pending manuscript, query for all similar articles that have been identified in open-access repositories and, separately, in preprint servers. Each returned match includes three similarity components. Compute a weighted match score for every returned article using the weights from the scoring configuration. If the article's identifier appears in the manuscript's declared-sources list, multiply that article's match score by the declared-source discount factor. After scoring all matches from both sources together, select the top N highest-scoring articles (where N is the maximum articles considered value from the configuration), compute their arithmetic mean as the composite base score, then multiply by the discipline adjustment factor for the manuscript's field. When fewer than N matches exist, average all available scores; when there are no matches at all, the composite base is zero.

Separately, check every author of the manuscript against the retraction watchlist. If an author appears, note the severity of their watchlist entry. When an author has more than one watchlist entry, use only the highest-severity penalty for that author. Sum the retraction penalties across all matched authors for the manuscript, add the total to the discipline-adjusted composite, and cap the result at one. This is the final risk score.

A manuscript is flagged when its final risk score meets or exceeds the flagging threshold. Flagged manuscripts receive a severity category: Critical when the score is at least 0.85, High when at least 0.75 but below 0.85, and Moderate when at least the threshold but below 0.75. A reference file maps these categories to review urgency and escalation requirements.

Save the full results as `originality_report.csv` containing these columns in this order: `manuscript_id`, `title`, `discipline`, `submission_date`, `composite_base_score`, `discipline_adjusted_score`, `retraction_penalty`, `final_risk_score`, `flag_status`. All score columns must carry four decimal places. The flag status column must read FLAGGED or CLEAR. Rows must be sorted by manuscript ID in ascending order.

Save a second file named `flagged_cases.json` as a JSON array where each element represents one flagged manuscript and includes the fields `manuscript_id`, `title`, `authors`, `discipline`, `submission_date`, `final_risk_score` (four decimal places), `severity_category`, `top_matching_articles` (a list of objects each with `article_id`, `source`, and `match_score` rounded to four decimal places), and `retraction_flags` (a list of objects each with `author` and `severity`). Entries in this array must be sorted by final risk score in descending order; when two entries share the same score after rounding to two decimal places, sort by submission date ascending, and if dates also match, by manuscript ID ascending.

In your final response, state the total number of manuscripts reviewed, the number flagged for review, the count in each severity category (Critical, High, Moderate), and list every flagged manuscript's identifier alongside its final risk score and severity category.
