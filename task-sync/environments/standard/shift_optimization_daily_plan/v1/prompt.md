You are responsible for generating a daily staffing plan at a manufacturing facility that operates multiple production lines, each equipped with several machines. The plan must assign operators to machines across every shift defined for the planning date, with the overarching goal of minimizing expected downtime by ensuring every operational machine is covered by a suitably qualified and reliable operator.

Begin by reading the shift configuration file to identify the planning date, the ordered list of shifts, and their time windows. Separately, read the staffing rules configuration to understand the constraints that govern valid assignments. Among these rules you will find a minimum certification level that every operator-machine pairing must satisfy, a stricter certification threshold that applies specifically to production lines whose priority is classified as critical or high, a maximum tolerable absence rate above which an operator must be excluded from consideration, and a severity threshold that determines whether an unresolved maintenance event renders a machine unavailable. The rules also specify how to rank competing candidates for the same machine: first by certification level in descending order, then by historical absence rate in ascending order, and finally by operator identifier in ascending order as a tiebreaker.

Next, collect all production target files that detail each production line's shift-level throughput requirements and priority classification. Every line that has a target entry for a given shift must be staffed during that shift; lines without a target entry for a particular shift should be skipped for that shift. Gather all operator availability files to learn which operators are scheduled and available for which shifts on the planning date.

Using the available tools, retrieve the full list of production lines and, for each line, the machines it contains along with their identifiers and types. Retrieve maintenance log data for each line to determine which machines are currently down: a machine counts as unavailable if it has any unresolved maintenance event whose severity meets or exceeds the threshold specified in the staffing rules. Retrieve the current certification records for each line to see which operators hold valid, non-expired certifications for which machines and at what level. Finally, obtain the historical absence rate for every operator who appears in any certification record by querying absence statistics in batches.

Once all data has been assembled, perform the assignment procedure shift by shift, processing shifts in the order given by the shift configuration. Within each shift, process production lines sorted first by priority according to the priority ordering in the staffing rules (critical before high before medium before low) and, among lines sharing the same priority, by line identifier in ascending alphabetical order. For each production line, consider only its operational machines, sorted by machine identifier in ascending order. For every such machine, identify candidate operators who hold a valid certification at or above the required level for that line's priority, who are available for the current shift, whose absence rate does not exceed the maximum, and who have not already been assigned to another machine during this same shift. Rank the candidates as the rules prescribe and assign the top-ranked candidate. If no eligible candidate remains, record the machine-shift slot as uncovered.

Save the resulting plan as `staffing_plan.csv` with columns `shift`, `production_line`, `machine_id`, `operator_id`, `operator_name`, `cert_level`, and `absence_rate`. Each row represents one assignment. The `absence_rate` values must be formatted to exactly two decimal places. Rows should appear in the order they were assigned: shifts in configuration order, lines within each shift in priority-then-identifier order, machines within each line in identifier order.

Separately, save a `coverage_summary.txt` file. This file should begin with the planning date and the total number of assignments, then list each shift followed by every production line with its priority and the fraction of operational machines that received an operator. After all shifts, list the machine identifiers that are under maintenance. If any machine-shift slots went uncovered, list them with the reason. End the file with an overall coverage line stating how many of the total operational machine-shift slots were filled and the corresponding percentage rounded to one decimal place.

In your final response, state the total number of assignments made, the overall coverage percentage to one decimal place, and the count of machines currently under maintenance. If any machine-shift slots could not be staffed, note them along with the reason.
