You are assisting a senior partner at an audit firm who needs a comprehensive review of recent engagement activity to identify potential scope creep, unauthorized work, and certification violations across the firm's active and completed engagements. The firm maintains records of staff time entries, file access events, engagement team assignments, and client document request histories, all of which can be queried through the available tools. Separately, the firm stores engagement-level scope and budget definitions in a series of YAML files, along with a flagging policy configuration, certification requirement mappings, and a task code category reference, all of which reside alongside the data you will be working with.

Your objective is to cross-reference every time entry against the active engagement assignments to determine whether any staff member has logged hours to an engagement they are not currently assigned to. Each such instance constitutes an unauthorized time entry and must be captured individually. In parallel, you must aggregate the total hours billed to each engagement and compare that figure against the budgeted hours defined in the engagement scope files. The flagging policy specifies two overrun percentage thresholds: one for medium severity and one for high severity. If an engagement's total billed hours exceed its budget by at least the medium threshold percentage, it should be flagged as a budget overrun, with severity determined by which threshold it crosses.

On a separate track, every file access log entry must be checked against the active assignments for that engagement. Any access event by a staff member who is not actively assigned to the engagement in question should be flagged as unauthorized access. Additionally, each client document request includes a scope area field, and the engagement scope YAML files list the authorized scope areas for every engagement. If a document request references a scope area that falls outside the authorized set for its engagement, that request represents an out-of-scope activity and must be flagged accordingly.

Finally, the certification requirements file maps each engagement type to a minimum certification level. For every active assignment, you should verify that the assigned staff member holds at least the required certification for the engagement type. If their certification level falls below the minimum, this constitutes a certification violation. When a single staff member has multiple active assignments to the same engagement, only one certification violation flag should be produced per unique engagement-staff pair.

Once all five categories of flags have been identified, compile them into a single CSV file named `flagged_activities.csv`. The file must contain exactly these columns in this order: `flag_id`, `flag_type`, `engagement_id`, `staff_id`, `staff_name`, `detail`, `severity`, `reference_date`. The `flag_type` values are `UNAUTHORIZED_TIME`, `BUDGET_OVERRUN`, `UNAUTHORIZED_ACCESS`, `OUT_OF_SCOPE_REQUEST`, and `CERTIFICATION_VIOLATION`. For budget overrun flags where no single staff member is responsible, the `staff_id` and `staff_name` fields should be left empty. The `reference_date` should be the entry date for time entries, the date portion of the access timestamp for file access flags, the request date for document requests, the assignment start date for certification violations, and left empty for budget overruns. Sort all flags first by `flag_type` alphabetically, then within each type by the relevant record identifier in ascending order, and assign sequential integer `flag_id` values starting from one across the entire sorted list.

In addition, produce a plain text file named `summary.txt` that states the total number of flags, then lists the count of flags broken down by each flag type, then lists the count broken down by severity level covering HIGH and MEDIUM, and finally enumerates every high-severity flag with its flag ID, type, engagement ID, staff ID, staff name, and detail. Your final response should state the total number of flagged activities, the distribution by type, and the distribution by severity.
