Every quarter the regional environmental compliance division conducts a comprehensive review of all registered industrial facilities to determine which ones pose the greatest risk of violating their discharge regulations. The assessment draws on multiple streams of information: current effluent sensor measurements recorded at each site, the legally permitted discharge limits established for each facility and pollutant combination, the historical record of inspection violations, the maintenance status of pollution-control equipment, independent laboratory analyses of discharge samples, and corrective action plans filed in response to past violations. Your task is to carry out this assessment and produce a single, prioritized dispatch list that field inspectors will use to schedule their upcoming site visits.

The evaluation covers every facility whose operating status is currently Active. For each such facility you must compute a composite risk score built from five distinct components, each carrying a weight defined in a scoring configuration file stored in the working directory.

The first component measures effluent exceedances. For every pollutant monitored at a facility, identify the most recent sensor reading and the corresponding permitted daily maximum. Independent laboratory analyses of discharge samples are also available in CSV files in the working directory; when the lab-verified value for a given facility and pollutant exceeds the sensor-reported value, the lab-verified value should be used in place of the sensor value for exceedance purposes. If a facility holds multiple permit records for the same pollutant, use the most restrictive limit. For each pollutant where the effective concentration exceeds the daily maximum, compute the fractional excess as the difference between the effective value and the limit divided by the limit, then multiply by the hazard-tier multiplier found in the pollutant classification reference file. Sum these across all pollutants to obtain the facility's exceedance component.

The second component captures inspection violation history. Each violation carries a severity rating on a one-to-five scale. Weight each violation's severity by a recency factor that depends on how many days have elapsed between the inspection date and the reference date specified in the scoring configuration: violations within the most recent ninety days receive one weight, those within one hundred eighty days another, those within three hundred sixty-five days another, and anything older receives yet another, all as specified in the configuration. Violations that remain unresolved are further scaled by an unresolved multiplier also found in the configuration. Sum the weighted severity values to produce the violation-history component.

The third component reflects maintenance risk. Count the number of maintenance log entries for the facility whose status is Overdue; this count is the maintenance risk component.

The fourth component addresses lab discrepancy. For each pollutant at the facility, compare the most recent sensor reading with the corresponding lab-verified value from the working directory. Count the number of pollutants for which the lab-verified value exceeds the sensor-reported value by more than ten percent of the sensor value. This count is the lab-discrepancy component.

The fifth component concerns corrective actions. Files in the working directory record the current status of corrective action plans associated with past violations, stored across multiple files in varying formats. Count the number of corrective actions marked as Overdue for each facility; this count is the corrective-action component.

Multiply each of the five component scores by its respective weight from the configuration, sum them to obtain a raw risk score, and then multiply the raw score by the environmental sensitivity zone multiplier assigned to the facility. Zone multiplier values are found in site assessment records stored as JSON files in the working directory. Round the final risk score to two decimal places.

Map the risk score to a risk category using the thresholds in the scoring configuration: scores at or above the highest threshold are categorized as CRITICAL, those at or above the next threshold as HIGH, those at or above the third threshold as MODERATE, and all others as LOW. Similarly, map the score to a dispatch urgency using the dispatch threshold values in the configuration: IMMEDIATE for the highest tier, PRIORITY for the next, ROUTINE for the next, and MONITOR for everything below. Identify each facility's primary concern as the risk component whose weighted contribution to the raw score before zone adjustment was the greatest, labeled as one of Exceedance, Violations, Maintenance, Lab Discrepancy, or Corrective Actions.

Save the complete assessment as a file named `dispatch_list.csv` containing the following columns in this exact order: `rank`, `facility_id`, `facility_name`, `region`, `risk_score`, `risk_category`, `primary_concern`, `dispatch_urgency`. Every Active facility must appear exactly once regardless of its risk level. Rows must be sorted by risk score from highest to lowest, with ties broken by facility identifier in ascending lexicographic order, and the rank column must reflect this ordering starting from one.

Once the file has been written, provide a brief narrative summary stating the total number of facilities assessed, the count of facilities falling into each risk category, and the facility identifiers together with names and risk scores of the five highest-risk facilities.
