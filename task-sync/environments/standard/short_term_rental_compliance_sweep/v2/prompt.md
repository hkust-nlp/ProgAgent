You are a municipal compliance analyst tasked with identifying properties that are operating as unpermitted short-term rentals. The city maintains records of property tax assessments, rental platform listings, monthly utility consumption, and occupancy permits, all of which you can query through the available tools. In addition, a collection of files has been provided to you containing complaint reports filed by residents, intelligence scraped from rental platforms, neighborhood digests, tax delinquency memos, and several configuration documents that define the enforcement rules, zoning regulations, and utility consumption baselines your analysis must follow.

Begin by reviewing the enforcement configuration file, which is stored in YAML format and specifies the base risk scores assigned to each violation type, the modifier bonuses applied when certain conditions are met, the overall risk-score cap, and the thresholds that determine which recommended enforcement action corresponds to each score range. You will also find a JSON file that maps each zoning code to whether short-term rentals are permitted in that zone and whether a permit is required. A CSV file provides baseline utility consumption rates per square foot per month, broken down by property type and size bracket; these baselines are essential for detecting anomalous usage patterns.

Your primary objective is to find every property that has at least one active rental listing on a platform yet lacks the legal right to operate as a short-term rental. A property is in violation if it falls into one of three categories. First, if the property sits in a zone where short-term rentals are outright prohibited, the violation type is "zoning_violation" regardless of any permits on file. Second, if the property is in a zone where short-term rentals require a permit but the property has no short-term rental permit on record at all, the violation type is "no_permit". Third, if such a permit exists but its status is expired, the violation type is "expired_permit"; if the permit is revoked or in any non-active state other than expired, treat it the same as having no permit. Properties in zones that allow short-term rentals without requiring a permit are not violations.

Once you have identified every violation property, compute a risk score for each one. Start with the base score that corresponds to the violation type as defined in the enforcement configuration. Then apply modifiers: add the complaint bonus if the total number of complaints filed against that property's address, as recorded across all complaint batch files, meets or exceeds the complaint threshold. Add the utility anomaly bonus if the property's average monthly electricity consumption, average monthly water consumption, or average monthly gas consumption over the full twelve months of 2025 exceeds the appropriate baseline rate multiplied by the property's square footage and then multiplied by the utility spike threshold. Add the extra listing bonus once for each additional active listing beyond the first. Finally, cap the risk score at the maximum defined in the configuration. Determine the recommended enforcement action by comparing the final risk score against the action thresholds in the configuration, checking from the highest tier downward.

Separately, gather estimated annual revenue figures from the platform intelligence files. Each intelligence entry is keyed by listing identifier and includes an estimated annual revenue; aggregate these by property, summing across all listings that belong to the same property.

Compile your findings into a CSV file named `compliance_cases.csv`. The file must contain the columns `property_id`, `address`, `owner_name`, `violation_type`, `risk_score`, `recommended_action`, and `evidence_summary`, in that exact order. Each row represents one violation property. The `evidence_summary` column should be a concise semicolon-separated string that includes the violation type, the number of complaints, whether a utility anomaly was detected, the number of active listings, and the estimated annual revenue. Sort the rows by risk score in descending order, breaking ties by property identifier in ascending order.

In your final response, state the total number of compliance violation cases you identified. Provide a breakdown showing how many cases fall under each violation type. Then list the top three highest-risk properties by their property identifiers, their risk scores, and their violation types.
