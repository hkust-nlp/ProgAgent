You have been brought in to evaluate every recruitment agency your company currently works with. Management needs a rigorous, data-driven vendor performance analysis that produces a scorecard for each agency along with a clear renewal recommendation. The analysis must draw on both the structured records accessible through the available query tools and the collection of data files and configuration documents stored in your working directory.

Begin by surveying all files in your working directory. Among them you will find a set of monthly financial reports that record each agency's retainer fees, placement fees, and total spend for each month. You will also find a scoring configuration file that defines the weights assigned to each performance metric, the normalization ranges for each metric, a retention threshold in months, and default values to use when an agency has zero hires. A separate tier definition file maps overall score ranges to performance tier labels. Finally, a renewal policy document lays out the conditional rules that determine which recommendation each agency receives based on its tier and individual metric values. All of these parameters must be applied exactly as specified in those files; do not invent or assume any thresholds, weights, or rules beyond what the files contain.

Five performance metrics must be calculated for every agency. The conversion rate is the count of candidates the agency placed who were ultimately hired divided by the total number of candidates the agency submitted. The average time to fill is the arithmetic mean, measured in calendar days, of the difference between each hired candidate's start date and that same candidate's original submission date, averaged across all of the agency's hires. The retention rate is the fraction of the agency's hires who either remain actively employed or whose total months retained meets or exceeds the retention threshold given in the configuration. The cost per hire equals the agency's total spend — the sum of the total_spend column across every monthly financial file in which the agency appears — divided by the agency's number of hires. The average quality score is computed by first averaging each hired candidate's interview scores across all of that candidate's interview rounds to get a per-candidate average, and then taking the mean of those per-candidate averages across all of the agency's hires.

For any agency that has zero hires, substitute the default metric values provided in the scoring configuration rather than attempting division by zero or leaving fields blank.

Once the raw metrics have been computed, normalize each one using the min and max bounds from the configuration. When the configuration indicates that higher values are better, the normalized value is the raw value minus the minimum divided by the maximum minus the minimum, clamped to the range zero through one. When lower values are better, the normalized value is one minus that same fraction, again clamped. Multiply each normalized metric by the corresponding weight from the configuration and sum the five weighted terms to produce the agency's overall score.

Assign each agency to a performance tier by comparing its overall score against the tier thresholds in the tier definition file. Use the rule stated in that file to select the correct tier. Then determine each agency's renewal recommendation by applying the rules in the renewal policy document in order, considering both the assigned tier and the agency's raw metric values wherever the rules reference them.

Save the completed analysis as `vendor_scorecard.csv` with columns in exactly this order: `agency_name`, `total_submissions`, `total_hires`, `conversion_rate`, `avg_time_to_fill_days`, `retention_rate`, `cost_per_hire`, `avg_quality_score`, `overall_score`, `tier`, `recommendation`. Sort rows by `overall_score` in descending order. Format `conversion_rate`, `retention_rate`, and `overall_score` to four decimal places, format `cost_per_hire` and `avg_quality_score` to two decimal places, and express `avg_time_to_fill_days` as a whole number.

In your final response, state the three highest-scoring agencies and the three lowest-scoring agencies by overall score, including each one's tier and recommendation, and briefly note which single metric most differentiated the top performers from the bottom performers.
