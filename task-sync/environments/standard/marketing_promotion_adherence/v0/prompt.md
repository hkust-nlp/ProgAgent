You are auditing franchisee compliance with national marketing promotions for a quick-service restaurant brand. Corporate headquarters runs several national promotions throughout the year, each specifying an exact discount percentage that every franchise location must honor at the point of sale. Some of these promotions are mandatory for all franchisees, while others are optional. Your job is to cross-reference multiple data sources to identify every instance of non-compliance and produce a consolidated corrective action list.

Start by reviewing the compliance configuration file and the promotion calendar file stored alongside the data you will be working with. The compliance configuration is in YAML format and defines the tolerance band for discount deviations, the maximum acceptable rate of invalid or expired coupon redemptions, severity classification thresholds for each violation type, and the recommended corrective actions that correspond to each severity level. The promotion calendar is a JSON file listing each promotion along with whether participation is mandatory or optional.

For each franchisee, retrieve their discount analysis to see the average discount percentage they actually applied for each promotion they participated in. Compare this against the required discount percentage for that promotion, which you can obtain by looking up the promotion details. If the absolute deviation between the average applied discount and the required discount exceeds the tolerance defined in the compliance configuration, that constitutes a discount violation. Classify the severity of the violation using the discount violation severity thresholds from the configuration: the deviation is compared against the minimum deviation percentage for each severity tier, starting from the most severe.

Separately, examine each franchisee's coupon redemption statistics across all promotions combined. Calculate the overall rate of invalid and expired redemptions as a percentage of total redemptions for that franchisee. If this rate exceeds the maximum coupon invalid rate percentage from the compliance configuration, flag it as a coupon violation. The promotion_id for coupon violations should be recorded as "ALL" and the promotion_name as "All Promotions" since the rate is computed across all promotions. Classify the severity using the coupon violation thresholds.

On top of this, review the advertising spend reports found in the ad_reports subdirectory. Each franchisee has a CSV file there containing their actual spend broken down by promotion and advertising channel. Sum the actual spend across all channels for each promotion and compare it against the minimum local ad spend requirement for that promotion, which is available in the promotion details. If the total actual spend falls below the minimum, this is an underfunded campaign violation. Compute the funding ratio as the percentage of actual spend relative to the minimum, and classify the severity using the underfunded campaign thresholds from the configuration, where a lower funding ratio maps to a more severe classification.

Additionally, check whether each franchisee has participated in every mandatory promotion. A franchisee is considered to have participated in a promotion if they have any point-of-sale transactions recorded for it. If a mandatory promotion has no transaction records for a given franchisee, flag it as a non-participation violation with severity HIGH.

Once you have identified all violations, compile them into a file called `corrective_actions.csv`. This file must contain the following columns in this exact order: `franchisee_id`, `franchisee_name`, `promotion_id`, `promotion_name`, `violation_type`, `severity`, `details`, `recommended_action`. The violation_type values must be exactly one of: `discount_violation`, `underfunded_campaign`, `coupon_violation`, or `non_participation`. The severity values must be one of: `CRITICAL`, `HIGH`, or `MEDIUM`. The recommended_action for each violation must match the corresponding action text from the compliance configuration file for that violation type and severity level.

For the details column of discount violations, use the format: "Average applied discount X.Y% vs required X.Y% (deviation: X.Y%)" where the percentages are rounded to one decimal place. For underfunded campaign violations, use: "Actual spend $X.XX vs minimum $X.XX (shortfall: $X.XX, funded X.Y%)" with dollar amounts to two decimal places and the funding percentage to one decimal place. For coupon violations, use: "Invalid/expired coupon rate X.Y% exceeds maximum X.Y% (N of M redemptions)" where N is the count of invalid plus expired redemptions and M is the total. For non-participation violations, use: "No transactions recorded for mandatory promotion 'Promotion Name'" where the promotion name is inserted.

The rows in the CSV must be sorted first by severity in descending order of importance (CRITICAL first, then HIGH, then MEDIUM), then by franchisee_id in ascending order, and finally by promotion_id in ascending order within the same severity and franchisee.

In your final response, provide a summary of the audit results including the total number of violations found, a breakdown of violations by type, and a breakdown by severity level. Confirm that the corrective actions file has been saved and state its column structure and sort order.
