You are tasked with producing a full monthly interconnect settlement reconciliation for HomeNet Telecom against every active partner carrier. The settlement covers a single billing period whose exact dates and parameters are specified in a JSON configuration file stored alongside the data files you will find in your working directory. That same directory contains several other configuration and data files in CSV, YAML, JSON, TXT, and Markdown formats; you must discover and use all of them, as no single source carries the complete picture.

Begin by identifying every carrier classified as an active partner. For each such partner, determine which network switches belong to that partner and which belong to HomeNet. You will need this mapping to attribute each call detail record to the correct pair of carriers. Only completed calls should be considered; records marked as failed or dropped must be excluded entirely. Furthermore, any call whose raw duration in seconds falls below the minimum billable duration threshold stated in the settlement rules configuration must also be excluded.

For every qualifying call, compute billable minutes by rounding the raw duration up to the next whole minute. Look up the base rate from the active bilateral agreement between HomeNet and the relevant partner for that call's type. On top of the base rate, check whether a rate adjustment applies for that carrier pair and call type, as listed in a YAML configuration file; a positive percentage is a surcharge and a negative percentage is a discount, applied multiplicatively to the base rate. Next, check whether the call's route identifier appears in a routing penalties file; if it does, apply the stated surcharge percentage on top of the already-adjusted rate, again multiplicatively. Finally, look up the call's quality score from the CDR quality batch files. If the score is strictly below the quality threshold defined in the settlement rules, multiply the effective rate by the quality penalty multiplier from that same configuration. The charge for the call is the product of billable minutes and the final effective rate, rounded to two decimal places.

Once per-call charges are computed, classify each call by direction. A call originating from a partner switch and terminating at a HomeNet switch is incoming traffic, meaning the partner owes HomeNet. A call originating from a HomeNet switch and terminating at a partner switch is outgoing traffic, meaning HomeNet owes the partner. Sum the charges in each direction separately for each partner.

After obtaining raw incoming and outgoing charge totals, apply a volume-based tier discount. The discount percentage is determined by the combined total of incoming and outgoing billable minutes for that partner, using the tier table found in a JSON configuration file. The discount reduces both incoming and outgoing charges proportionally, so multiply each by one minus the discount percentage divided by one hundred, and round the result to two decimal places.

Separately, examine the dispute records for the current billing period whose status is resolved. For each such dispute that involves HomeNet and the partner in question, regardless of which party filed it, retrieve the approved credit amount from the dispute memo files rather than the original disputed amount. Sum those credits per partner and round to two decimal places. Dispute credits are subtracted after the tier discount has been applied.

The net settlement for a partner equals the tier-discounted incoming charges minus the tier-discounted outgoing charges minus the dispute credits, rounded to two decimal places. A positive value means the partner owes HomeNet; a negative value means HomeNet owes the partner.

Save the results as `invoice_summary.csv` sorted by carrier_id in ascending order. The file must contain exactly these columns in this order: `carrier_id`, `carrier_name`, `total_incoming_minutes`, `total_outgoing_minutes`, `incoming_charges`, `outgoing_charges`, `tier_discount_pct`, `dispute_credits`, `net_settlement`. Monetary values must appear with exactly two decimal places. The tier discount percentage should appear with one decimal place.

In your final response, state the total net settlement across all partners rounded to two decimal places, and name the partner carrier that has the highest absolute net settlement value.
