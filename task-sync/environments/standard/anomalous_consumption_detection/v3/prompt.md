You are an energy utility analyst tasked with identifying residential households that exhibit anomalous electricity consumption. Your investigation draws on several data sources: smart meter interval readings accessible through the provided tools, a household appliance registration database also available via tools, daily weather observations from a local station queryable through tools, and tariff rate schedules obtainable the same way. In addition, billing batch files in CSV format and maintenance log files in JSON format are available alongside configuration files that define the detection thresholds and prioritization rules you must follow.

Begin by collecting a complete roster of all households served by the utility, paging through the full listing. For every household, retrieve the associated smart meter identifier, the full set of registered appliances, and the daily meter readings spanning the entire observation period present in the data. You will also need the daily weather observations covering that same date range, which you should obtain once and reuse across all household analyses.

The core of your analysis rests on comparing each household's actual metered consumption against an expected baseline derived from its registered appliances. For a given household, compute the base expected daily consumption in kilowatt-hours by summing, over every registered appliance, the product of that appliance's rated wattage and its average daily hours of use, divided by one thousand. This base figure must then be adjusted for weather: a YAML configuration file specifies a heating temperature threshold and a cooling temperature threshold, along with corresponding coefficients. On any day when the observed temperature falls below the heating threshold and the household uses electric or heat-pump heating, increase the daily factor by the heating coefficient multiplied by the difference between the heating threshold and the observed temperature, divided by ten. Similarly, when the temperature exceeds the cooling threshold, increase the factor by the cooling coefficient multiplied by the excess over the cooling threshold divided by ten; this cooling adjustment applies to all heating types. For households whose heating type is gas, only the cooling adjustment applies. Multiply the base expected daily consumption by this weather factor for each day, then sum both the adjusted expected totals and the actual metered totals across the full observation period.

Compute a deviation ratio as the difference between total actual and total expected consumption divided by total expected consumption. A configuration file in YAML format provides the consumption anomaly threshold; any household whose absolute deviation ratio exceeds this threshold is flagged as a consumption anomaly. To classify the anomaly, consult the maintenance log files: if the household's meter has any recorded maintenance issue other than "none", the anomaly type is "faulty_meter"; otherwise it is "unauthorized_usage".

Separately, check every household for billing discrepancies regardless of whether a consumption anomaly was found. From the billing batch CSV files, obtain the billed kilowatt-hours for each household. Compare the billed figure against the total actual metered consumption: if the absolute difference divided by the actual consumption exceeds the billing discrepancy threshold given in the same YAML configuration, and the household was not already flagged as a consumption anomaly, classify it as "billing_discrepancy".

Once all anomalous households have been identified and classified, assign each a priority score according to the rules laid out in the Markdown priority-rules document found among your files. That document specifies a base score for each anomaly type and a deviation bonus formula, as well as the recommended field action string for each type. Compute the final priority score, rounded to one decimal place.

Produce a file named `inspection_list.csv` containing one row per anomalous household, sorted in descending order of priority score with household identifier as the ascending tie-breaker. The CSV must include columns in exactly this order: `household_id`, `meter_id`, `address`, `zone`, `anomaly_type`, `deviation_ratio`, `priority_score`, `recommended_action`. The deviation ratio should be rounded to two decimal places.

After writing the file, provide a brief summary stating the total number of anomalous households found, a breakdown of how many fall into each anomaly type, and the identifiers and priority scores of the three highest-priority entries.
