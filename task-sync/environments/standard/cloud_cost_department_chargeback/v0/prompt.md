Your organization operates across multiple cloud providers and needs a comprehensive reconciliation of infrastructure spending for the current billing period. The goal is to produce a complete per-department showback and chargeback report that accounts for billing adjustments, tag-compliance penalties, reserved-instance utilisation inefficiencies, and shared-services cost allocation.

Begin by gathering all billing records through the available querying tools. Each billing record contains a base cost for a resource on a given date. These base costs must be adjusted using daily billing-adjustment files that are provided as CSV files, each covering one day of the billing period. Every adjustment file supplies, for each resource on that date, a negotiated discount percentage, a volume credit amount, and a support-tier surcharge percentage. The adjusted cost for a single record is computed as follows: the discount amount equals the base cost multiplied by the negotiated discount percentage divided by one hundred; the surcharge amount equals the base cost multiplied by the support-tier surcharge percentage divided by one hundred; the adjusted cost then equals the base cost minus the discount amount plus the surcharge amount minus the volume credit.

To determine which department each resource belongs to, consult the JSON file that maps cloud account identifiers to their respective departments and cloud providers. Each resource is billed under a specific account, and each account belongs to exactly one department. Reserved instances are linked to specific resources, and department assignment for reserved instances follows the same account-based mapping used for billing records.

Produce a file called `showback_report.csv` containing the columns `department`, `cloud_provider`, `base_cost_total`, `discount_total`, `surcharge_total`, `credit_total`, and `adjusted_cost_total`, with one row per department-and-cloud combination. All monetary values must be rounded to two decimal places. Rows should be sorted first by department in ascending alphabetical order, then by cloud provider in ascending alphabetical order.

Separately, assess the tag-compliance status of every resource by querying the resource-tag records. A policy configuration file in YAML format specifies a surcharge percentage that applies to non-compliant resources. For each department, the tag-compliance surcharge equals the sum of adjusted costs across all non-compliant resources belonging to that department, multiplied by the surcharge percentage from the policy, divided by one hundred.

Examine reserved-instance utilisation records to identify underutilised instances. The same policy file defines an underutilisation threshold as a percentage and a penalty percentage. For each daily reserved-instance record where utilisation falls below the threshold, the wasted capacity cost equals the RI hourly rate multiplied by the difference between hours reserved and hours used. The penalty for that record equals the wasted capacity cost multiplied by the penalty percentage from the policy divided by one hundred. Sum all such daily penalties per department to obtain the total RI underutilisation penalty for that department.

Shared-services costs must also be allocated across departments. A CSV file lists centralised service costs with a monthly total for each service. A JSON file provides the headcount for every department. The allocation method specified in the policy file determines how to distribute these costs; under headcount-proportional allocation each department receives a share equal to the total shared-services cost multiplied by that department's headcount divided by the sum of headcounts across all departments.

Produce a file called `chargeback_report.csv` with columns `department`, `showback_total`, `tag_compliance_surcharge`, `ri_underutilisation_penalty`, `shared_services_allocation`, and `total_chargeback`. The showback total for a department is the sum of its adjusted costs across all clouds. The total chargeback equals the showback total plus the tag-compliance surcharge plus the RI underutilisation penalty plus the shared-services allocation. One row per department, sorted alphabetically by department, all values rounded to two decimal places.

Produce a file called `ri_savings_report.csv` with columns `department`, `cloud_provider`, `total_ri_cost`, `on_demand_equivalent`, `ri_savings`, and `avg_utilisation_pct`. For each department-and-cloud combination that has reserved instances, the total RI cost is the sum of the RI hourly rate multiplied by hours reserved across all daily records in that group. The on-demand equivalent is the sum of the on-demand rate multiplied by hours used. RI savings equals the on-demand equivalent minus the total RI cost. The average utilisation percentage is the arithmetic mean of utilisation percentages across all daily RI records for that group. Sort by department then cloud provider, all values rounded to two decimal places. Include only department-and-cloud combinations that actually have reserved-instance records.

Once chargeback amounts are determined, assess budget variance. Query cost-centre budgets for each department for the billing period indicated in a text file that describes budget-variance assessment rules. That same file explains how to compute the effective budget: it equals the sum of budget amounts plus the sum of carry-over amounts across all of a department's sub-departments for the specified billing period. Produce a file called `budget_variance.csv` with columns `department`, `effective_budget`, `total_chargeback`, `variance`, and `variance_pct`. The variance equals total chargeback minus effective budget, and the variance percentage equals the variance divided by the effective budget multiplied by one hundred. Sort by department, all values rounded to two decimal places.

The budget-rules file also specifies an over-budget threshold as a percentage. Any department whose variance percentage exceeds this threshold is flagged as over-budget.

In your final response, state the total company-wide adjusted spend across all departments and clouds on a line formatted exactly as `TOTAL_ADJUSTED_SPEND: ` followed by the value rounded to two decimal places. On a separate line, state the department with the highest total chargeback formatted as `TOP_DEPARTMENT: ` followed by the department name. On another line, list all departments flagged as over-budget in a comma-separated list sorted alphabetically, formatted as `OVER_BUDGET_DEPARTMENTS: ` followed by the names separated by `, `. If no departments are over budget, write `None` after that label.
