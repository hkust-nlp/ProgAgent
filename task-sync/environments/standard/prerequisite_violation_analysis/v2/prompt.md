You are an academic-affairs analyst tasked with auditing prerequisite enforcement across a university's course registration system. The university maintains records of every student, every course and its prerequisite chain, every registration attempt, and every transcript entry, all of which you can query through the available tools. In addition to the queryable records, a set of data files has been provided that contain information you cannot obtain through tools alone: a grade-point conversion table that maps each letter grade to its numeric value, an enforcement-policy document that specifies how to classify the severity of each violation and what thresholds trigger recommendations, advisor-override records that document cases where an advisor explicitly waived a prerequisite requirement, and student-advisor assignment mappings that connect each student to their designated academic advisor.

Your goal is to identify every instance in which a student was approved to register for a course without having satisfied all of that course's prerequisite requirements beforehand. A prerequisite is considered unsatisfied if the student either never completed the prerequisite course in a semester prior to the registration semester, or completed it but earned a grade whose numeric value (according to the grade-point conversion table) falls strictly below the minimum grade specified for that prerequisite. Each such unsatisfied prerequisite for a given registration constitutes a separate violation. Only approved registrations should be examined; denied or waitlisted attempts are not violations.

Once you have assembled the complete set of violations, classify each one by severity. The enforcement-policy document defines three severity tiers: critical applies when the prerequisite was never taken at all and the course falls within the student's declared major department, major applies either when the prerequisite was never taken but the course is outside the student's major or when the prerequisite grade was insufficient and the course is within the major, and minor applies when the prerequisite grade was insufficient and the course is outside the student's major. After classifying severity, determine whether each violation has a corresponding advisor-override record in the provided data files by matching on student, course, and prerequisite. If a match exists, mark the violation as overridden and capture the stated reason; otherwise mark it as not overridden.

Sort all violations first by severity in the order critical then major then minor, and within the same severity level sort by student identifier in ascending lexicographic order, breaking further ties by course identifier ascending. Write the full violation listing to a file called `violation_report.csv` with exactly these columns in this order: `student_id`, `student_name`, `course_id`, `course_name`, `missing_prereq_id`, `violation_type`, `severity`, `has_override`, `override_reason`, `semester`. The `violation_type` column must contain either `missing` or `grade_insufficient`. The `has_override` column must contain either `yes` or `no`. The `override_reason` column should contain the reason text from the override record when one exists, or be empty when it does not. The `semester` column records the semester in which the violating registration was approved.

Separately, produce a file called `policy_recommendations.json` containing a JSON object with the following top-level keys. Under `summary`, include an object with integer fields `total_violations`, `overridden_violations`, and `unresolved_violations`. Under `by_department`, include a list of objects each having `department` and `violations` fields, sorted by violation count descending. Under `top_violated_courses`, include up to five objects each having `course_id` and `violation_count`, sorted by count descending with course identifier ascending as a tiebreaker. Under `recommendations`, include a list of recommendation strings: for every department whose violation count meets or exceeds the department alert threshold defined in the enforcement-policy file, emit the department code followed by a colon and the corresponding recommendation rule text from that file; do the same for every course meeting or exceeding the course alert threshold; and for every advisor whose total number of approved overrides (across all override records in the data files) meets or exceeds the advisor alert threshold, emit the advisor name followed by a colon and the advisor-related recommendation rule text.

Once both files have been written, provide a final summary that states the total number of violations found, how many were overridden versus unresolved, and the count at each severity level.
