You are an anti-piracy analyst for a large online education platform. The platform offers lecture content gated by subscription tiers, and external monitoring has surfaced evidence that some lectures are being redistributed outside the platform. Your job is to identify every pirated lecture, quantify the severity of each case, and produce a prioritized takedown list for the enforcement team.

The detection methodology document and the policy and configuration documents stored alongside the data are the authoritative specification: they define which evidence sources establish that a lecture has been pirated, how content fingerprints are matched and false positives discarded, how each piracy signal is counted, the signal weights, the tier-based multipliers, the scoring formula and its rounding, the minimum score for inclusion, the priority-level brackets, and the enforcement action for each priority. Every number and classification in your output must follow those definitions exactly — assume nothing beyond them.

Produce a file called `takedown_list.csv` containing one row per pirated lecture that meets the score threshold. The file must have the following columns in this exact order: `rank`, `lecture_id`, `lecture_title`, `course_title`, `access_tier`, `piracy_score`, `priority_level`, `num_external_sources`, `external_urls`, `unauthorized_access_count`, `watchlist_ip_hits`, `recommended_action`. The `piracy_score` column should display the value to two decimal places. The `external_urls` column should contain all unique external URLs for that lecture joined by semicolons, sorted alphabetically. Sort the rows by piracy score in descending order; break ties by lecture identifier in ascending order. Number the ranks starting from one.

In your final response, include exactly these four summary lines, each on its own line, with the integer counts filled in: "Total pirated lectures requiring action: N", "Critical priority: N", "High priority: N", "Medium priority: N".
