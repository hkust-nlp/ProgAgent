You are responsible for generating a daily staffing plan at a manufacturing facility that operates multiple production lines, each equipped with several machines. The plan must assign operators to machines across every shift defined for the planning date, with the overarching goal of minimizing expected downtime by ensuring every operational machine is covered by a suitably qualified and reliable operator.

The staffing policy and configuration documents stored alongside the data are the authoritative specification for the plan: they define the planning date and shift order, which machine-shift slots require staffing, when a machine counts as unavailable, which operators are eligible for a given machine and shift, how competing candidates are ranked, and the exact order in which slots must be processed. Follow that specification exactly — the procedure is order-dependent, because every assignment you make removes that operator from the candidate pool for the remainder of the shift. Every assignment must also be registered in the plant's central shift roster system, one record per assignment, so that the system of record reflects the final plan.

Save the resulting plan as `staffing_plan.csv` with columns `shift`, `production_line`, `machine_id`, `operator_id`, `operator_name`, `cert_level`, and `absence_rate`. Each row represents one assignment. The `absence_rate` values must be formatted to exactly two decimal places. Rows should appear in the order they were assigned: shifts in configuration order, lines within each shift in priority-then-identifier order, machines within each line in identifier order.

Separately, save a `coverage_summary.txt` file. This file should begin with the planning date and the total number of assignments, then list each shift followed by every production line with its priority and the fraction of operational machines that received an operator. After all shifts, list the machine identifiers that are under maintenance. If any machine-shift slots went uncovered, list them with the reason. End the file with an overall coverage line stating how many of the total operational machine-shift slots were filled and the corresponding percentage rounded to one decimal place.

In your final response, state the total number of assignments made, the overall coverage percentage to one decimal place, and the count of machines currently under maintenance. If any machine-shift slots could not be staffed, note them along with the reason.
