You are responsible for evaluating the operational health of every fluid catalytic cracking unit across a multi-refinery petrochemical operation. The organization maintains a comprehensive set of records spanning catalyst performance, feedstock characteristics, unit throughput, and energy consumption. Your objective is to synthesize these disparate data sources into a single, actionable maintenance priority list that ranks every unit from most urgent to least urgent for catalyst intervention, whether that means regeneration, replacement, or continued monitoring.

The policy and reference documents stored alongside the data are the authoritative specification: they define the performance factors and exactly how each is calculated, the scoring weights and normalization ranges, the energy unit conversion factors, the feedstock severity weights, the score thresholds that delineate priority tiers, the decision rules that map priority tier and catalyst age together to a recommended maintenance action and estimated downtime, the fixed reference date used for all age calculations, and how edge cases are resolved. Feedstock quality data arrives as a collection of dated report files residing in the same location and must be aggregated per unit; all other operational data is available through the provided query tools. Nothing beyond those documents should be assumed, and every calculation must follow them.

Rank all units in descending order of priority score. If two units share the same score, the one whose unit identifier comes first alphabetically should rank higher. Assign integer ranks starting from one. Save the complete ranked list as `maintenance_priority.csv` with the following columns in this exact order: `unit_id`, `unit_name`, `priority_rank`, `priority_score`, `activity_decline_rate`, `energy_efficiency_ratio`, `feedstock_severity_score`, `conversion_loss_pct`, `catalyst_age_days`, `recommended_action`, `estimated_downtime_days`. All numeric values should be rounded to two decimal places.

In your final response, state how many units were analyzed, then list every unit that falls into the Critical or High priority tier, giving for each its unit identifier, unit name, tier designation, priority score, recommended action, and estimated downtime in days. Conclude by noting that the full priority list has been saved to the output file.
