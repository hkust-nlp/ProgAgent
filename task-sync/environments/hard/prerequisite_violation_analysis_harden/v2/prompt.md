You are an academic-affairs analyst tasked with auditing prerequisite enforcement across a university's course registration system. Your goal is to identify every instance in which a student was approved to register for a course without having satisfied all of that course's prerequisite requirements beforehand, classify each violation by severity, reconcile each one against advisor-override records, and turn the findings into policy recommendations.

The policy and reference documents stored alongside the data are the authoritative specification for this audit. They define the audit methodology and violation criteria, the grade-point conversion table, the severity classification rules, the alert thresholds and recommendation rule texts, the advisor-override records, and the student-advisor assignments. Follow them exactly.

Sort all violations first by severity in the order critical then major then minor, and within the same severity level sort by student identifier in ascending lexicographic order, breaking further ties by course identifier ascending. Write the full violation listing to a file called `violation_report.csv` with exactly these columns in this order: `student_id`, `student_name`, `course_id`, `course_name`, `missing_prereq_id`, `violation_type`, `severity`, `has_override`, `override_reason`, `semester`. The `violation_type` column must contain either `missing` or `grade_insufficient`. The `has_override` column must contain either `yes` or `no`. The `override_reason` column should contain the reason text from the override record when one exists, or be empty when it does not. The `semester` column records the semester in which the violating registration was approved.

Separately, produce a file called `policy_recommendations.json` containing a JSON object with the following top-level keys. Under `summary`, include an object with integer fields `total_violations`, `overridden_violations`, and `unresolved_violations`. Under `by_department`, include a list of objects each having `department` and `violations` fields, sorted by violation count descending with department code ascending as a tiebreaker. Under `top_violated_courses`, include up to five objects each having `course_id` and `violation_count`, sorted by count descending with course identifier ascending as a tiebreaker. Under `recommendations`, include a list of recommendation strings: for every department whose violation count meets or exceeds the department alert threshold defined in the enforcement-policy file, emit the department code followed by a colon and the corresponding recommendation rule text from that file; do the same for every course meeting or exceeding the course alert threshold; and for every advisor whose total number of approved overrides (across all override records in the data files) meets or exceeds the advisor alert threshold, emit the advisor name followed by a colon and the advisor-related recommendation rule text.

Once both files have been written, provide a final summary that states the total number of violations found, how many were overridden versus unresolved, and the count at each severity level.
