You are a senior case officer analyst working in a consular operations center. Your task is to conduct a comprehensive review of all active visa applications across every embassy in the system, identify those that have become stalled, and produce a prioritized intervention list covering the stalled applications that also qualify as high-priority.

The policy and configuration documents stored alongside the data are the authoritative specification for this review. They define which applications count as active, the exact conditions, thresholds, and reason codes under which an application is considered stalled, what qualifies an application as high-priority, the formula for computing each intervention priority score, and how each entry's recommended action is determined. You must apply those documents exactly rather than inventing your own criteria; the applicant case dossiers they reference are likewise stored alongside the data.

For every application on your intervention list, you must also file an intervention request in the case management system, routed to the applicant's own embassy queue and carrying that applicant's recommended action, so the escalation shows up for the responsible case officers.

Produce a file called `intervention_list.csv` containing exactly the following columns in this order: `applicant_id`, `full_name`, `visa_category`, `embassy_id`, `priority_score`, `stall_reasons`, `recommended_action`, `days_stalled`. The stall reasons column must list all applicable stall reason codes separated by a semicolon and a space. Sort the rows by priority score in descending order, breaking ties by days stalled in descending order, and further ties by applicant ID in ascending lexicographic order.

After writing the file, provide a brief summary stating how many stalled high-priority applications were found and listing the top entries with their scores, stall reasons, and recommended actions, and confirm that the intervention requests have been recorded in the system.
