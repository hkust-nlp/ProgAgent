You are the scheduling coordinator for a school that needs to finalize student timetables for the upcoming semester. Every student must be placed into exactly six course sections, one for each time slot in the daily schedule. Some of these courses are mandatory core requirements dictated by the student's academic program and grade level, while the remaining slots should be filled with elective courses drawn from each student's preference survey.

Course catalogs, section offerings, student rosters with academic records, and teacher-to-section assignments are accessible through the school's information system, while the files available to you hold complementary records that cannot be obtained any other way — the elective preference surveys, the teachers' contracted availability, and the mapping of core course requirements to each program and grade — together with the policy and configuration documents that govern the entire procedure. Those documents are the authoritative specification for the order in which students are processed, which sections are eligible to receive enrollments, how to choose among eligible sections, and how ties are broken; follow them exactly, because every placement changes the remaining capacity that later decisions depend on.

As you finalize each student-slot placement, record the enrollment in the school's enrollment system so that the official roster database reflects the completed timetable.

After processing every student, save the complete timetable as `timetable.csv`. This file must contain exactly these columns in this order: `student_id`, `student_name`, `time_slot`, `course_id`, `course_name`, `section_id`, `teacher_id`. Each row represents one student-slot assignment. The rows should be sorted by student identifier in ascending order, and within each student by time slot in ascending numerical order.

Once the file is written, report the following four summary statistics in your final response. State the total number of students who appear in the timetable as `total_students_scheduled: N`. State how many of those students have all six time slots filled as `fully_scheduled_students: M`. State the total number of assignment rows in the timetable as `total_assignments: K`. Finally, compute the average preference rank of all elective assignments across all students, rounded to two decimal places, and report it as `avg_elective_preference_rank: X.XX`. An elective assignment's preference rank is the rank the student gave that course in their survey; core course assignments are excluded from this calculation.
